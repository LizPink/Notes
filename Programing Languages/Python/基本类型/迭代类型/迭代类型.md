这一章我们介绍Python中的一类重要类型——==Iterable==可迭代类型。
# 枚举类型
本章我们将介绍Python中的==Enumerate==类型，该类型能够同时返回索引值和元素值的信息。
```python
# Enumerate
"""
Parameters
----------
start: int
	用于调整地址的表示方式，默认使用0表示第一个地址索引。
"""
enumerate(
	iterable	iterable: Iterable
	start=0		start: int
)

```
枚举类型的对象支持遍历循环，遍历循环中每次都会得到一个索引值和索引值对应的元素值。
```python
# Iteration in Enumerate
for index, value in enumerate:
	print(f"the index is {index}, and the value is {value}")
```
# 映射类型
本章我们将介绍Python中的==Map==类型，该类型体现了函数式编程的算法设计思想。
```python
# Map
map = map(
	func,
	iterable
)
```
在实际应用中，经常将==Map==转变为其他如==List==等类型获取计算的结果。
