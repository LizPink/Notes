# 矩阵微分运算
在这里我们展示常见矩阵的微分与导数计算结果，首先我们约定向量默认采用列向量布局，其次约定所有函数的导数采用雅各比布局的方式。这种布局方式的结果是微分式分别满足
$$
\begin{aligned}
	& df=(\nabla_{\bm{x}}f)d\bm{x} \\[0.5em]
	& d\bm{f}=(J_\bm{x}\bm{f})d\bm{x} \\[0.5em]
\end{aligned}
\tag{1}
$$
其中雅各比矩阵这样布局的含义比较明显，就是向量值函数在每个维度上都可视为对应维度的梯度点乘自变量增量。

| 函数形式                                        | 微分                                                                                                                                        | 导数                                                                                    | 备注   |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | ---- |
| ***标量函数***                                  | <                                                                                                                                         | <                                                                                     | <    |
|                                             | *一次型*                                                                                                                                     | <                                                                                     | <    |
| $$f(\bm{x})=a$$                             | $$da=\bm0^Td\bm{x}$$                                                                                                                      | $$\nabla_{\bm x}f:=\frac{da}{d\bm x}=\bm{0}^T$$                                       |      |
| $$f(\bm{x})=\boldsymbol{x}$$                | $$d\boldsymbol{x}=\bm{1}^Td\bm{x}$$                                                                                                       | $$\nabla_{\bm x}f:=\frac{d\bm x}{d\bm x}=1^T$$                                        | 标准微分 |
| $$f(\bm{x})=\bm{a}^T\bm{x}$$                | $$d\bm{a}^T\bm{x}=\bm{a}^Td\bm{x}$$                                                                                                       | $$\frac{d\bm{a}^T\bm{x}}{d\bm x}=\bm{a}^T$$                                           |      |
| $$f(\bm{x})=\bm{x}^T\bm{a}$$                | $$d\bm{x}^T\bm{a}=\bm{a}^Td\bm{x}$$                                                                                                       | $$\frac{d\bm{x}^T\bm{a}}{d\bm{x}}=\bm{a}^T$$                                          |      |
| $$f(\bm{x})=\bm{a}^T\bm{x}+\bm{b}^T\bm{x}$$ | $$\begin{aligned} d\bm{a}^T\bm{x}+\bm{b}^T\bm{x}&= \bm{a}^Td\bm{x}+\bm{b}^Td\bm{x} \\[0.5em] &=(\bm{a}^T+\bm{b}^T)d\bm{x} \end{aligned}$$ | $$\nabla_{\bm x}f:=\frac{d\bm{a}^T\bm{x}+\bm{b}^T\bm{x}}{d\bm{x}}=\bm{a}^T+\bm{b}^T$$ |      |
|                                             | *二次型*                                                                                                                                     | <                                                                                     | <    |
| $$f(\bm{x})=\bm{x}^T\bm{x}$$                | $$d\bm{x}^T\bm{x}=2x^Tdx$$                                                                                                                | $$\nabla_{\bm x}f:=\frac{d\bm{x}^T\bm{x}}{d\bm{x}}=2\bm{x}^T$$                        |      |
| $$f(\bm{x})=\bm{x}^TA\bm{x}$$               | $$d\bm{x}^TA\bm{x}=\bm{x}^T(A+A^T)d\bm{x}$$                                                                                               | $$\nabla_{\bm x}f:=\frac{d\bm{x}^TA\bm{x}}{d\bm x}=\bm{x}^T(A+A^T)$$                  |      |
这里默认元素函数$e_i:\mathbb{R}\to\mathbb{R},g$是可微函数.
