# 模块引用
本章我们介绍C++中的一些标准模块，这些模块拓展了C++的语法功能，就类似于Python语言中的拓展模块。要引入一个标准模块，你需要在`main`文件的最开始引入这些模块。
```c++
/* Introduce a module */
#include <name_of_module>

// Example
#include <iostream>
```
当我们在代码文件中引入了另外一个模块，并且想要使用这个模块中的内容，我们就需要使用模块对应的命名空间名称和`::`域解析操作符来使用他们的内容。
```c++
#include <iostream>

int main()
{
	a = std::string("abcd");
	std::cout << a;
	
	return 0;
}
```
