这一部分我们来介绍整数类型的基础知识。整数类型是C++中的一类基础类型，也是一类重要类型。在C++中整数类型还有很多细分类型，我们现在一一予以介绍。其中`size_t`类型是不同环境 (指令集架构、操作系统、编译器、标准库) 共同决定的一个适当大小的类型，它的表达范围足够表达当前环境中任何对象的内存大小。

| 类型名                | 内存大小     | 表示范围              |
| ------------------ | -------- | ----------------- |
| *有符号整型*            |          |                   |
| short              | 2 Byte   |                   |
| int                | 4 Byte   |                   |
| long               | 4-8 Byte |                   |
| long long          | 8 Byte   |                   |
| *无符号整型*            |          |                   |
| unsigned short     |          |                   |
| unsigned int       |          |                   |
| unsigned long      |          |                   |
| unsigned long long |          |                   |
| *固定宽度整型*           |          |                   |
| int32_t            | 4 Byte   |                   |
| int64_t            | 8 Byte   |                   |
| uint32_t           | 4 Byte   |                   |
| uint64_t           | 8 Byte   |                   |
| *语义整型*             |          |                   |
| size_t             | x Byte   | 当前环境能通用表示大小的无符号整型 |
