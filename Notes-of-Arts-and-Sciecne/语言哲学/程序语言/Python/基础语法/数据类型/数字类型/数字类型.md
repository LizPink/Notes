在Python中数字类型大体上可以分为整数和分数类型，其中整数类型包括布尔型和整型，分数类型主要是浮点型。
# 类型转换
数字类型之间的类型转换经常发生，比如在数字类型内部进行运算时，运算结果会转化为优先级最高的数字类型。又比如可以通过类型转换函数强制将其他类型转换为数字类型。
## 整数类型转换
```python
# int
"""
Parameters
----------
x: bool|int|float|str
	指定需要转换为int的变量类型。当输入类型为float时，只截取对应的整数部分。
"""

int(
	x=0: bool|int|float|str,
	base: int
) -> int
```
