## 作用范围
在Python根据代码的结构可以将代码分为Local、Enclosure、Global、BuiltIn（LEGB）四大类命名空间，标识符的在不同命名空间内的可见性质称为标识符的作用域。

关于如何判定一个标识符属于哪一个作用域，在Python中判别依据是是否出现绑定行为：解释器会将当前代码块中*触发过绑定行为的标识符判定为当前代码块内的局部变量。*而不具有绑定行为的变量（比如不涉及赋值操作的变量、通过`globl`、`nonlocal`声明的变量）判定为自由变量，自由变量的值会按照LEGB的顺序进行查找。

```python
# Example1
count = 0

## Wrong Solution
def increment():
	count += 1
	return count	# UnboundLocalError!
	
## Correct Solution
def increment():
	global count
	count += 1
	return count
```

## 内存特性
在Python中类型基本上分为可变类型和不可变类型两类，典型的不可变类型为`bool`、`int`、`float`、`str`、`tuple`等，典型的可变类型为`list`、`dict` 、`set`、`class`等。不可变类型不能进行原地修改，可变类型可以通过特定方法进行原地修改。
```python
# Example1
## 元组内部保存的引用不能被替换，但是引用的对象可以被原地修改。
a = (1,2, [3,4])
print(id(a))		# id1

a[2].append(5)
print(id(a), a)		# id1; [1,2,[3,4,5]]
```
