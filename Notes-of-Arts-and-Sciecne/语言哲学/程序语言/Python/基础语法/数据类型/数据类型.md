# 类型的范围
类型标识符有命名空间和作用域两个重要概念。所谓命名空间就是标识符所绑定对象的信息表，而作用域就是一个标识符在不同命名空间的作用范围。命名空间可以分为Local -> Enclosure -> Global -> BuiltIn（LEGB）四个大范围。

在Python中，编译器和解释器对于标识符所绑定对象的判定规则是：如果没有额外声明，对于赋值语句的标识符在局部空间内寻找对应的绑定对象，对于非赋值语句的标识符按照LEGB的顺序查找该变量所绑定的对象。
