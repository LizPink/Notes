## 列表的删除

| 函数     | 功能   |
| ------ | ---- |
| pop    | 原地删除 |
| remove | ^    |
| clear  | ^    |
```python
# List.pop
element = list.pop(
	index[pos] = -1
)

# List.remove
list.remove(
	value[pos]
)
```
在进行列表元素删除的时候，我们需要注意列表动态删除陷阱，也就是说在一次遍历过程中不能够保证完全删除期望的元素。一个解决方案是多次遍历并删除，直到所有的期望元素得到删除为止。
