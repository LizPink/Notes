# 字典的定义
## Dict
字典的key是根据hash值确定唯一性的，因此能够作为字典的key的元素首先必须能够支持hash计算。
```python
# Null Dict
dictionary = {}
dictionary = Dict()
```
```python
# Dict from List
dictionary = Dict([key1, value1], [key2, value2])

# Dict from Tuple
dictionary = Dict([(key1, value1), (key2, value2)])

# Dict from String
dictionary = Dict(["str1", "str2"])		# 字符串能且仅能包含两个元素
```
同时可以通过`zip()`函数将两个序列对象一一对应的生成一个字典。
```python
# Dict from Zip
dictionary = Dict(Zip(Sequence1, Sequence2))
```

同时可以通过`fromkeys()`函数快速生成一个字典。
```python
# Dict.fromkeys
dict.fromkeys(
	Iterable,
	uniform_value
)
```
## Counter
在Python的`collections`模块中可以具有针对字典进行改进做的数据类型，其中一类重要的类型是计数字典Counter类型。
```python
import collections
counter = collections.Counter(
	iterable
)
```

# 字典的访问
字典类型可以通过`keys()`,`values()`,`items()`函数获取其键、值、键值对，返回的对象分别是`dict_keys`,`dict_values`,`dict_items`类型。这些类型仍但属于序列对象，支持遍历访问，但是不支持索引与切片访问。


同时字典也可以通过`[]`表达式或者`get()`方法进行访问。

## 字典的删除
```python
# Dict.pop
"""
Parameters
----------
key: String
	用于指定被删除的键。
Error_Value:
	如果被删除的key不存在，默认抛出KeyError，但是可以通过该参数指定返回一个错误值。

Returns
-------
返回被删除key对应的value。
"""
element = dict.pop(
	*key,
	*Error_Value
)
```
