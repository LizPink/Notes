## b-String
在Python中字符串一般是按照unicode码点进行存储的，除此之外还可以指定具体编码格式的字符串，称为bytes类型字符串，该类型字符串以具体的编码形式存储。
```python
# bytes string
"""
Parameters
----------
	encoding: ["ascii", "gbk","utf-8", "utf-16", "utf-32"]
"""
b"..."			# encoding = ascii
bytes(
	str,
	encoding
)
```
特别地对于ascii码字符串，可以通过`ord`和`chr`实现数字类型和字符类型之间的转换。
## f-String
f字符串主要用于对数字输出进行格式控制，具体的语法规则如下：
```python
# format control for f-string
"""
f"{表达式:格式规则}"

Parameters
----------
默认乘以基数100.默认右对齐，默认用空格填充。
"""
print(
	f"{number:.4f}",		# 保留4位小数
	f"{number:.4%}",		# 保留4位小数，按照百分比显示
	f"{number:10.4f}",		# 保留4位小数，输出至少10个字符
	f"{number:<10.4f}",		# 保留4位小数，输出至少10个字符，左对齐
	f"{number:0<10.4f}"		# 保留4位小数，输出至少10个字符，左对齐，不足用0填充
)
```

## 元素删除

| 函数     | 功能  | 备注   |
| ------ | --- | ---- |
| strip  |     | 非原删除 |
| lstrip |     | ^    |
| rstrip |     | ^    |
```python
# String.strip
"""
Parameters
----------
chars: String
	指定要删除的字符集。
"""
string.strip(
	chars
)

# Example
"#-msg-#".strip("-#")	# output: "msg"
```
