序列类型是一种最常见的容器类型，在Python中的使用也是最多的。

# 序列的访问
## 索引与切片访问
序列类型可以通过索引或者切片的方式进行元素访问。
![[序列类型的结构.png|602]]
```python
sequence[index]

sequence[start:stop:step]
```
## 遍历访问
在序列对象中可以通过`for`或者`while`循环语句实现对其内部元素的遍历访问。
```python
# for-loop
for element in list:
	print(element)
```

```python
# min max for sequence
"""
Parameters
----------
key: Function
"""
min(
	Iterable,
	key
)
```
排序函数是序列对象最通用的函数之一，它能够按照一定的key将序列进行排序，并且根据reverse指定升序还是降序。
```python
# sorted for sequence
"""
Parameters
----------
reverse: bool
	默认采用升序排列
"""
sorted(
	Iterable,
	key,
	reverse=False
)
```
