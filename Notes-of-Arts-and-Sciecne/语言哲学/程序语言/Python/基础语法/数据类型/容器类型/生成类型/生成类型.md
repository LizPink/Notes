生成器类型是Python中另外一类重要类型，生成器是一种可迭代类型。生成器具有惰性迭代的特性，每一次迭代只将需要计算的数据加载进入内存中。生成器具有流特性，生成器遍历过后的数据不可以再次访问。

生成器类型经常用于大量数据的读取。
```python
# Example1
squares_gen = (x**2 for x in range(1_000_000))		# Generator Comprehension
squares_list = [x**2 for x in range(1_000_000)]

## 打印两个变量的内存大小
print(f"Generator size: {squares_gen.__sizeof__()} bytes")	# ~0  Bytes
print(f"List size: {squares_list.__sizeof__()} bytes")		# ~8M Bytes
```

# 生成器的组合
生成器具有管道(Pipeline)的特性，也就是说一个生成器可以作为另一个生成器的数据源。
```python
def positive_filter(data:Iterable):
    for x in data:
        if x>0:
            yield x

def normalizer(data:Generator, min_val, max_val):
    for x in data:
        yield (x-min_val) / (max_val - min_val)

# Pipe Generator:
raw_data = [10, -20, 20, 30, -5, 15]
filtr_generator = positive_filter(raw_data)
norme_genetator = normalizer(filtr_generator, min_val=0, max_val=100)

for value in norme_genetator:	# 10,20,30,15
    print(f"{value:.2f}")
```
