# 正则表达函数
在Python的`re`模块中内置了正则表达式的函数，可以应用正则表达式来辅助字符串的算法任务。

| 函数      | 功能        |
| ------- | --------- |
| match   | 从头匹配，匹配一次 |
| search  | 任意匹配，匹配一次 |
| findall | 任意匹配，匹配多次 |
| split   | 按照规则切分    |
| sub     |           |
参数`flag`的取值会影响匹配的规则：

| 参数  | 功能  |
| --- | --- |
|     |     |

```python
# re.match
"""
Usage
-----
从头开始匹配字符串。

Returns
-------
匹配成功则返回Match对象，匹配失败则返回NoneType对象。
"""
re.match(
	pattern,
	string,
	flag
)
```
```python
# re.search
"""
Returns
-------
匹配成功则返回Match对象，匹配失败则返回NoneType对象。
"""
```
切分函数`split()`主要通过匹配规则让正则引擎对字符串进行切分，返回一组切分列表。
```python
# re.split
```
注意到`split()`所采用的算法可能会切分出空字符串。
```pseudo code
result = []
start = 0

每次从左到右找到一个分隔符 " ":
    把 start 到分隔符之前的内容切出来
    加入 result
    start 移动到分隔符后面

最后把剩下的内容加入 result
```

---

```python
# re.sub
"""
Parameters
----------
repl: String | Function
	指定替换的字符串或者字符串替换函数。如果传递的一个字符串函数，那么会将匹配得到的Match对象作为参数逐个传递给该函数。
"""
re.replace(
	pattern,
	repl,
	string
)
```

## 匹配信息
通过`re.match()`方法匹配之后会得到一个Match对象，通过调用这个对象的接口可以得到的具体的匹配信息。

| 函数                | 功能          |
| ----------------- | ----------- |
| m.start(),m.end() | 匹配对象的起止索引   |
| m.span()          | 匹配索引组成的元组   |
| m.group()         | 返回匹配到的字符串素材 |
| m.groups()        | 返回普通分组      |
| m.groupdict       | 返回命名分组      |


## 优化情况
实际上我们可以通过`re.compile()`方法将正则表达式转化为一个`Pattern`匹配模式对象，并且进一步利用这个对象进行匹配。
