推导表达式是Python中列表、字典、集合等可变类型的一种简洁的定义方法。
```python
# Example1
weekdays = ["Mon", "Tue", "Wed", "Thu", "Fri"]
temperatures = [22.0, 19.5, 25.5, 18.5, 23.0]

avg_temp = sum(temperatures) / len(temperatures)

## List Comprehension
list = [temp for temp in temperatures if temp > avg_temp]

## Dict Comprehension
dict = {weekday:temp for weekday, temp in zip(weekdays, temperatures) if temp > avg_temp}

## Nested Comprehension
matrix = [[1,2,3], [4,5,6], [7,8,9]]
flat_matrix = [x for row in matrix for x in row]

## Generator Comprehension
generator = (temp for temp in temperatures)
generator_list = [(x for x in row) for row in matrix]
```
