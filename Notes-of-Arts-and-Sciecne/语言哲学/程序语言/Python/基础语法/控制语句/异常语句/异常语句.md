在Python中异常类是按照这个结构进行设计的。
```text
BaseException
├── SystemExit
├── KeyboardInterrupt
├── GeneratorExit
└── Exception
    ├── ValueError
    ├── TypeError
    ├── IndexError
    ├── KeyError
    └── RuntimeError
```
```python
iscubclass(Exception, BaseException)	# output: True
```

## Try Clause
最常见的异常控制语句为`try...except`语句，该语句可以控制编译通过之后的异常。需要注意的是无论是否有异常、或者异常是否被捕获到，语句`finally`都会执行，如果出现了无法捕获的异常，则会先执行`finally`语句再抛出异常。
```python
# try ... except
try:
	...
except 错误类型 as e:		# e:表示错误信息文本
	...
else:
	...
finally:
	...
```
具体的例子如下：
```python
## Example1
try:
	...
except Esception as e:		# exception: 可以捕获基于Exception的类型
	...
	
## Example2
try:
	...
except ValueError as e1:
	...
except NameError as e2:
	...
```
### 控制原则
在进行异常控制的时候，应当优先将具体的错误类置于通用的错误类之前，因为Python在匹配错误时会考虑类的继承关系。

## Raise Clause
另外一个异常控制语句是`raise`语句
```python
raise 错误类型对象
```

## Assert Clause
另外一个异常控制语句是`assert`语句，当表达式expr出现异常时，可以通过创建并返回`AssertError(args)`对象并抛出错误。
```python
assert expr, args
```
