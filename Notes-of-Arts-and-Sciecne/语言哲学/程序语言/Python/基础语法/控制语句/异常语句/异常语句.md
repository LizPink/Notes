# 异常控制语句
## Try Clause
最常见的异常控制语句为`try...except`语句，该语句可以控制编译通过之后的异常。需要注意的是无论是否有异常、或者异常是否被捕获到，语句`finally`都会执行，如果出现了无法捕获的异常，则会先执行`finally`语句再抛出异常。
```python
# try ... except
try:
	...
except 错误类型 as e:		# e:表示错误信息文本
	...
else:
	...
finally:
	...
```
具体的例子如下：
```python
## Example1
try:
	...
except Esception as e:		# exception: 可以捕获基于Exception的类型
	...
	
## Example2
try:
	...
except ValueError as e1:
	...
except NameError as e2:
	...
```
### 控制原则
在进行异常控制的时候，应当优先将具体的错误类置于通用的错误类之前，因为Python在匹配错误时会考虑类的继承关系。

## Raise Clause
另外一个异常控制语句是`raise`语句
```python
raise 错误类型对象
```

## Assert Clause
另外一个异常控制语句是`assert`语句，其核心语法形式如下。当表达式为True时，继续执行后续代码;否则当表达式为False时，创建`AssertionError(message)`对象并抛出错误。
```python
assert condition message 

## Example1
x = 10
assert x > 10, "x应该大于10"
print("断言语句通过...")

## Example2
values = [True, False, False]
assert any(values)	# passed
assert all(values)	# not passed
```


# Python 常见异常类型

## 一、语法与缩进异常

|异常类型|触发场景|示例|说明|
|---|---|---|---|
|`SyntaxError`|Python 语法不合法|`if x > 0 print(x)`|通常在代码解析阶段产生|
|`IndentationError`|缩进层级不正确|`if True:` 后没有缩进|`SyntaxError` 的子类|
|`TabError`|Tab 和空格混合导致缩进不一致|不同代码行使用不同缩进字符|`IndentationError` 的子类|

## 二、名称、作用域与成员访问异常

|异常类型|触发场景|示例|说明|
|---|---|---|---|
|`NameError`|使用了当前作用域中不存在的名称|`print(undefined_var)`|检查变量是否定义或名称是否拼错|
|`UnboundLocalError`|局部变量在赋值前被读取|`x += 1`，但函数内尚未定义 `x`|`NameError` 的子类|
|`AttributeError`|对象不存在指定成员|`"abc".append("d")`|常见于类型判断错误或成员名拼写错误|

## 三、类型与参数值异常

|异常类型|触发场景|示例|说明|
|---|---|---|---|
|`TypeError`|对象类型不支持当前操作|`"1" + 2`|参数类型错误、参数数量错误也可能触发|
|`ValueError`|参数类型正确，但具体值不合法|`int("abc")`|类型正确不代表取值有效|
|`OverflowError`|数值运算结果超出可表示范围|`math.exp(1000)`|Python 整数通常不会溢出，但部分浮点运算会|
|`FloatingPointError`|浮点运算发生错误|NumPy 配置严格浮点检查后除零|Python 内置浮点运算中较少直接出现|

### `TypeError` 和 `ValueError` 的区别

|情况|异常|
|---|---|
|参数的类型不符合要求|`TypeError`|
|参数类型正确，但值不符合要求|`ValueError`|

```python
len(10)       # TypeError：int 类型不支持 len()
int("hello")  # ValueError：字符串类型可以传入，但内容无法转换
```

## 四、容器与查找异常

|异常类型|触发场景|示例|说明|
|---|---|---|---|
|`IndexError`|序列索引越界|`[1, 2][10]`|常见于列表、元组和字符串|
|`KeyError`|字典中不存在指定键|`{"a": 1}["b"]`|可使用 `dict.get()` 避免部分情况|
|`LookupError`|序列或映射查找失败|—|`IndexError` 和 `KeyError` 的共同父类|

## 五、算术异常

|异常类型|触发场景|示例|说明|
|---|---|---|---|
|`ZeroDivisionError`|除数或模数为零|`10 / 0`|整数、浮点数和复数运算都可能触发|
|`ArithmeticError`|算术运算发生错误|—|多种算术异常的父类|
|`OverflowError`|运算结果过大|`math.exp(1000)`|`ArithmeticError` 的子类|
|`FloatingPointError`|浮点运算失败|—|`ArithmeticError` 的子类|

## 六、导入异常

|异常类型|触发场景|示例|说明|
|---|---|---|---|
|`ImportError`|模块中的名称无法导入|`from math import unknown`|导入对象失败|
|`ModuleNotFoundError`|找不到需要导入的模块|`import unknown_module`|`ImportError` 的子类|

### 两者的区别

```python
import unknown_module
# ModuleNotFoundError：整个模块不存在

from math import unknown_name
# ImportError：math 存在，但其中没有 unknown_name
```

## 七、文件与操作系统异常

|异常类型|触发场景|示例|说明|
|---|---|---|---|
|`OSError`|操作系统相关操作失败|文件、目录、进程或设备操作失败|多种系统异常的父类|
|`FileNotFoundError`|文件或目录不存在|`open("missing.txt")`|`OSError` 的子类|
|`FileExistsError`|创建的文件或目录已经存在|`os.mkdir("existing")`|常见于目录创建|
|`PermissionError`|当前进程没有操作权限|打开无权限文件|检查文件权限和运行身份|
|`IsADirectoryError`|把目录当作普通文件操作|`open("folder")`|目标实际是目录|
|`NotADirectoryError`|把普通文件当作目录使用|访问 `file.txt/data`|路径中的某部分不是目录|
|`TimeoutError`|系统操作超时|网络或进程操作超时|`OSError` 的子类|
|`InterruptedError`|系统调用被信号中断|操作系统信号中断调用|一般较少手动处理|

```python
try:
    with open("data.txt", encoding="utf-8") as file:
        content = file.read()
except FileNotFoundError:
    print("文件不存在")
except PermissionError:
    print("没有读取权限")
except OSError as error:
    print(f"其他系统错误：{error}")
```

## 八、网络连接异常

|异常类型|触发场景|说明|
|---|---|---|
|`ConnectionError`|网络连接相关操作失败|多种连接异常的父类|
|`ConnectionRefusedError`|对方拒绝建立连接|服务可能未启动或端口未开放|
|`ConnectionResetError`|对方强制重置连接|已建立的连接被远端终止|
|`ConnectionAbortedError`|连接被中止|本地或系统终止连接|
|`BrokenPipeError`|向已关闭的管道或连接写入数据|常见于进程通信和 Socket|

这些异常均属于 `OSError` 系列。

## 九、字符编码异常

|异常类型|触发场景|示例|说明|
|---|---|---|---|
|`UnicodeError`|Unicode 编码或解码失败|—|Unicode 异常的父类|
|`UnicodeEncodeError`|字符串无法编码为目标字节格式|`"你好".encode("ascii")`|字符串转换为字节时发生|
|`UnicodeDecodeError`|字节无法按照指定编码解码|`b"\xff".decode("utf-8")`|字节转换为字符串时发生|
|`UnicodeTranslateError`|Unicode 字符转换失败|字符映射转换失败|相对少见|

## 十、运行时与资源异常

|异常类型|触发场景|示例|说明|
|---|---|---|---|
|`RuntimeError`|运行时发生无法归入其他类别的错误|不满足特定运行状态|通用运行时异常|
|`RecursionError`|递归深度超过限制|函数无限递归调用自身|`RuntimeError` 的子类|
|`MemoryError`|无法分配足够内存|创建过大的对象|程序此时可能已处于不稳定状态|
|`ReferenceError`|弱引用指向的对象已经被回收|访问失效的 `weakref.proxy`|普通引用通常不会触发|

```python
def recursive():
    recursive()

recursive()
# RecursionError
```

## 十一、输入、迭代与生成器异常

|异常类型|触发场景|说明|
|---|---|---|
|`EOFError`|`input()` 尚未读取到数据就遇到输入结束|常见于管道输入或手动结束标准输入|
|`StopIteration`|迭代器已经没有下一个元素|`next()` 调用时产生|
|`StopAsyncIteration`|异步迭代器已经结束|用于异步迭代协议|
|`GeneratorExit`|生成器被关闭|调用生成器的 `close()` 时传入|

正常的 `for` 循环会自动处理 `StopIteration`：

```python
iterator = iter([1])

next(iterator)  # 1
next(iterator)  # StopIteration
```

## 十二、开发与程序设计异常

|异常类型|触发场景|示例|说明|
|---|---|---|---|
|`AssertionError`|`assert` 条件为假|`assert x > 0`|主要用于调试和内部不变量检查|
|`NotImplementedError`|方法或功能尚未实现|抽象接口的默认方法|通常由开发者主动抛出|

```python
class Shape:
    def area(self):
        raise NotImplementedError("子类必须实现 area()")
```

注意：

- `NotImplementedError` 是异常类。
    
- `NotImplemented` 是一个特殊常量。
    
- 两者不是同一个东西。
    

## 十三、程序终止类异常

|异常类型|触发场景|说明|
|---|---|---|
|`KeyboardInterrupt`|用户按下 `Ctrl + C`|表示用户主动中断程序|
|`SystemExit`|调用了 `sys.exit()`|用异常机制执行程序退出|
|`GeneratorExit`|生成器被关闭|通知生成器结束执行|

这三个异常直接继承或间接继承自 `BaseException`，但不继承普通的 `Exception`。

因此：

```python
try:
    run_program()
except Exception:
    print("捕获普通程序异常")
```

通常不会捕获 `KeyboardInterrupt` 和 `SystemExit`，这样用户仍然可以终止程序。


## 十五、异常捕获建议

|建议|示例或说明|
|---|---|
|优先捕获具体异常|优先使用 `except FileNotFoundError`，而不是直接捕获所有异常|
|子类写在父类前面|先捕获 `FileNotFoundError`，再捕获 `OSError`|
|避免裸 `except`|`except:` 会同时捕获程序退出和键盘中断|
|不要静默忽略异常|避免只有 `except Exception: pass`|
|保留异常对象|使用 `except ValueError as error:`|
|无法处理时让异常继续传播|不必在每一层函数中捕获异常|
|清理资源使用 `finally`|无论是否异常都会执行|
|文件等资源优先使用 `with`|上下文管理器会自动清理资源|

推荐结构：

```python
try:
    result = perform_operation()
except ValueError as error:
    print(f"输入值错误：{error}")
except OSError as error:
    print(f"系统操作失败：{error}")
else:
    print(f"操作成功：{result}")
finally:
    print("清理资源")
```
