# For-Loop
在Python中循环`for`语句本质上是对一个可迭代对象重复调用`next()`方法直到不能调用为止。

循环`For-Loop`语句经常用于遍历一个可迭代对象，常用的遍历方式包括：
```python
# for-loop through Iterable

## 1: General Loop
for index in range(0, len(Iterable)):
	print(Iterable[index])
	
## 2: Direct Loop
for element in Iterable:
	print(e)

## 3: Enumerate Loop
for index, element in enumerate(Iterable, start=0):
	print(f"idx: {index}, element: {element}")
	
## 4: Zip Loop:
for element1, element2 in zip(Iterable1, Iterable2):
	print(f"ele1: {element1}, ele2: {element2}")
```
