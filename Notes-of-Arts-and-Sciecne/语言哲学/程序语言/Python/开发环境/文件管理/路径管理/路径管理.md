路径管理是Python文件管理的重要内容之一。在现代Python编程中经常使用`pathlib`来管理文件路径。对于`pathlib.Path`类型，该模块为我们定义了如下接口。

| 函数         | 功能       |
| ---------- | -------- |
| ***对象创建*** | <        |
| Path()     |          |
| ***对象性质*** | <        |
| str()      | 转换为字符串对象 |
| is_dir()   |          |
| is_file()  |          |
| ***路径操作*** |          |
| mkdir()    |          |
| ***路径运算*** | <        |
| /          | 路径连接     |
|            |          |
