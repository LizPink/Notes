# 类与对象的定义
```python
Class 类名:
	pass
```
## 类与对象的属性
可以为类和实例定义各自的属性，属性可以通过`类名.属性名`或者`实例名.属性名`进行访问，或者通过类与实例的方法进行访问。可以同时为类和实例定义同名的属性，二者属于不同的命名空间与作用域，此时属性访问顺序是从"实例->类"逐层查找。
```python
# Class or Instance Attributes
类名.属性名
实例名.属性名

类名.访问方法()
实例名.访问方法()
```

### 属性显示
在类与对象中可以通过`__str__(self)`和`__repr__(self)`方法修改对象在`print()`等函数下的显示内容。一般推荐先写repr函数。
```python
def __str__(self):
	...
	return ...
```
```python
def __repr__(self):
	...
	return ...
```

## 类与对象的方法
类与对象的函数可以分为三大类：静态方法、类方法、对象方法。
```python
# Static Method
@staticmethod
def static_function(*args, **kwargs):
	pass
```
```python
# Class Method
@classmethod
def class_method(cls, *args, **kwargs):
	pass
```
```python
# Instance Method
def instance_method(self, *args, **kwargs):
	pass
```

在类中可以通过`@property`（getter）和`@property.setter`两个装饰器将函数封装成属性进行使用。

在继承中如果子类没有对应的方法，编译器会沿着基类进一步寻找标识符对应的方法。
## 类与对象的生命
注意实际开发过程中，我们一般不会定义新的``__new__``方法而是默认调用基类object的同名方法。
```python
# __new__
class 类名:
	def __new__(cls, *args, **kwargs):
		pass
```
方法``__new()__``负责创造一个类对象，在此之后编译器会自动调用``__init__()``方法为这个类对象进行初始化。

```python
# __del__
```

## 类与对象的自省
在Python定义了一些关于类的元函数，用来描述一个类与对象的属性与方法相关的信息，称为反射函数（reflexive function）或者自省函数。

| 函数                            | 功能            |
| ----------------------------- | ------------- |
| getattr(obj, name)            | 返回obj对象中的某个对象 |
| issubclass(subcls, parentcls) |               |
```python
# getattr
"""
Usage
-----
返回对象obj命名空间中name绑定的对象。

Parameters
----------
"""
getattr(
	obj,
	name
)
```
