# 类与对象的定义
在Python中定义一个类型，首先需要关注：构造函数、初始化函数、析构函数，分别对应`__new()__`、`__init()__`、`__del()__`三种方法。这三种抽象反映了类对象的生命周期。在实践中我们通常只需要对初始化函数进行显式定义就可以了。类似于函数的重载，我们也可以通过`@classmethod`装饰器重载初始化函数。
```python
# Class Definition
import typing.ClassVar

class 类名:
	类属性:ClassVar[T] = 默认值
	实例属性:T
	
	# 构造函数：初始化
	def __init__(self):
		pass
	
	# 构造函数：初始化重载
	@staticmethod
	def from_params(cls. *args, **kwargs):
		instance = cls()
		...
		return instance
```

随后我们会关注：类的属性、对象的属性的概念。其中类属性只需要通过类就能调用，而对象属性必须通过创建对象才能调用。
```python
# Class Definition
import typing.ClassVar

class 类名:
	类属性:ClassVar[T] = 默认值
	实例属性:T
	
	# 构造函数：初始化
	def __init__(self, *args, **kwargs):
		pass
```
```python
## Example1
class Student:
    school_name:ClassVar[str] = "Python Academy"	## 类属性
    name:str										## 实例属性
    student_id:str									## 实例属性
    scores:dict[str, float]						## 实例属性

    def __init__(self, name:str, student_id:str, scores:dict[str, float]):
        self.name = name
        self.student_id = student_id,
        self.scores = scores
```
然后我们会关注：类函数、类方法、实例方法。所谓的类函数有点类似于C++中的友元函数，功能上用不到类的相关信息，但是因为架构组织的原因放到了类中，使用时通过类或者类对象都可以调用；类方法也是可以通过类或者对象调用，实例方法则必须通过对象调用。
```python
# Class Definition
import typing.ClassVar

class 类名:
	类属性:ClassVar[T] = 默认值		# 注意显式声明为ClassVar
	实例属性:T						# 注意在这里只做类型标注，否则会被认为是类属性。
	
	# 构造函数：初始化
	def __init__(self, *args, **kwargs):	# 这里要注意避免多个实例共享同一属性的问题
		self.实例属性:T = 初始值
		...
	
	# 类函数
	@staticmethod
	def func():
		pass
		
	# 类方法
	@classmethod
	def func(cls):
		pass
	
	# 实例方法
	def func(self):
		pass
```

### 显示属性
在类与对象中可以通过`__str__()`和`__repr__()`魔术方法方法修改类的显示属性。repr面向开发者，描述该对象的创建过程；str面向一般用户，返回更加可以理解的描述。一般推荐实现repr函数。
```python
def __str__(self):
	...
	return ...
```
```python
def __repr__(self):
	...
	return ...
```

### 自省属性
在Python定义了一些关于类的元函数，用来描述一个类与对象的属性与方法相关的信息，称为反射函数（reflexive function）或者自省函数。

| 函数                            | 功能            |
| ----------------------------- | ------------- |
| getattr(obj, name)            | 返回obj对象中的某个对象 |
| issubclass(subcls, parentcls) |               |
```python
# getattr
"""
Usage
-----
返回对象obj命名空间中name绑定的对象。

Parameters
----------
"""
getattr(
	obj,
	name
)
```
## 类与对象的方法
类与对象的函数可以分为三大类：静态方法、类方法、对象方法。

```python
# Static Method
@staticmethod
def static_function(*args, **kwargs):
	pass
```
类型方法一般通过`类名.方法名()`进行调用，具体的调用方法如下：
```python
# Class Method
@classmethod
def class_method(cls, *args, **kwargs):
	pass
	
## Example1 Bank Account
    @classmethod
    def from_string(cls, data:str) -> BankAccount:
        """
        Parameters
        ----------
        data: str
            形式如"Alice,S001,1000"
        """
        parse = data.split(sep=",")
        if not BankAccount.is_valid_account_number(parse[1]):
            raise ValueError("Invalid Account Number!")
        return cls(parse[0], parse[1], float(parse[2]))
```
```python
# Instance Method
def instance_method(self, *args, **kwargs):
	pass
```

在类中可以通过`@property`（getter）和`@property.setter`两个装饰器将函数封装成属性进行使用。

在继承中如果子类没有对应的方法，编译器会沿着基类进一步寻找标识符对应的方法。
### 方法协议
在Python中为类型设置相应的魔术方法，可以让这个类型支持特定的操作，不同操作需要不同的魔术方法被定义，实现每一类操作所需要定义的魔术方法称为协议。

| 协议与方法                                    | 调用形式                                                                                       | 触发语法                                   |
| ---------------------------------------- | ------------------------------------------------------------------------------------------ | -------------------------------------- |
| ***初始化协议***                              | <                                                                                          | <                                      |
| `__init__`                               | `obj.__init__(args)`                                                                       | `obj = class(args)`                    |
| ***显示协议***                               | <                                                                                          | <                                      |
| `__str__`                                | `obj.__str__()`                                                                            | `str(obj)`<br>`print(obj)`             |
| `__repr__`                               | `obj.__repr__()`                                                                           | `repr(obj)`                            |
| ***长度协议***                               | <                                                                                          | <                                      |
| `__len__`                                | `obj.__len__()`                                                                            | `len(obj)`                             |
| ***索引协议***                               | <                                                                                          | <                                      |
| `__getitem__`                            | `obj.__getitem__(key)`                                                                     | `obj[key]`                             |
| `__setitem__`                            | `obj.__setitem__(key, value)`                                                              | `obj[key] = value`                     |
| `__delitem__`                            | `obj.__delitem__(key)`                                                                     | `del obj[key]`                         |
| ***迭代协议***                               | <                                                                                          | <                                      |
| `__iter__`                               | `obj.__iter__()`                                                                           | `for item in obj`                      |
| `__next__`                               | `iterator.__next__()`                                                                      | `next(iterator)`                       |
| ***比较协议***                               | <                                                                                          | <                                      |
| `__eq__`                                 | `a.__eq__(b)`                                                                              | `a == b`                               |
| `__lt__`, `__le__`<br>`__gt__`, `__ge__` | `a.__lt__(b)`, `a.__le__(b)`<br>`a.__gt__(b)`, `a.__ge__(b)`                               | `a < b`, `a <= b`<br>`a > b`, `a >= b` |
| ***算术协议***                               | <                                                                                          | <                                      |
| `__add__`                                |                                                                                            |                                        |
| ***调用协议***                               | <                                                                                          | <                                      |
| `__call__`                               | `obj.__call__(arg1, arg2)`                                                                 | `obj(arg1, arg2)`                      |
| ***访问协议***                               | <                                                                                          | <                                      |
| `__get__`<br>`__set__`                   | `descriptor.__get__(self, instance ,class)`<br>`descriptor.__set__(self, instance, class)` | `obj.attr`<br>`obj.attr = value`       |

#### 迭代器协议
```python
## Example1
from typing import Iterable

class DataContainer:
    def __init__(self, data:Iterable):
        self.data = data
    def __iter__(self) -> Iterable:	# 必须返回一个迭代器类型
        self._index = 0
        return self.data

container = DataContainer([10, 20, 30])
isinstance(DataContainer, Iterable)	# True
for element in container:
	print(element)		# 10, 20, 30
```

## 类与对象的装饰
在[[语言哲学/程序语言/Python/基础语法/数据类型/函数类型/函数类型]]中我们介绍了函数装饰器，在类与对象中我们也有类中也有类装饰器。类装饰器是通过定义一个类实现的对函数对象或者类对象的装饰，在Python中类命名空间中的某个成员，只要其类型实现了`__get__(self, instance, class)`，通过点号访问该成员时，就会自动调用这个方法。
### 类方法装饰器
类方法装饰器的定义形式如下。
```python
# Class-Method Decorator:
class MethodDecorator:
    def __init__(self, params):
		pass
    def __get__(self, params):
        pass
    def __set__(self, params):
    	pass
```
类方法装饰器的具体例子如下。
```python
## Example1 Bank Account
class MyProperty:
    def __init__(self, fget):
        self.fget = fget
    def __get__(self, ins, cls):	# 调用时自动传入实例和类信息
        if obj is None:
            return self
        return self.fget(obj)

### 两个等价写法（1）
class BankAccount:
    def __init__(self, balance):
        self._balance = balance
    @MyProperty
    def balance(self):
        return self._balance
### 两个等价写法（2）
class BankAccount:
    def balance(self):
        return self._balance
    balance = MyProperty(balance)
```
类方法装饰器之所以能够运行是因为其实现了Python类与对象的描述符协议，所谓的Python协议就是如果一个类定义了一些魔术方法，那么这个类对象就支持特定的操作，而描述符协议允许类对象进行属性访问`obj.x`与属性赋值`obj.x = value`等操作。
```python
# Class Decorator
class ClassDecorator:
	def __init__(cls, params):
		pass
```
```python
from dataclass import dataclass
## Example1 Student
### 等价写法（1）
@dataclass
class Student:
    name: str
    age: int
    score: float
    
### 等价写法（2）
class Student:
    name: str
    age: int
    score: float = 0.0
Student = dataclass(Student)

### 等价写法（3）
class Student:
    name: str
    age: int
    score: float
    def __init__(self, name, age, score):
        self.name = name
        self.age = age
        self.score = score
    def __repr__(self):
        return f"Student(name={self.name!r}, age={self.age!r}, score={self.score!r})"
    def __eq__(self, other):
        if not isinstance(other, Student):
            return NotImplemented
        return (self.name == other.name and self.age == other.age and self.score == other.score)
```
