# 类的继承
## 抽象基类
在类与对象编程的实践中，经常会设计一个基类，负责为一个类设计统一的接口骨架。基类本身不能创建实例，只负责提供接口的约定。在Python中`abc`模块为我们提供了统一的抽象基类`ABC`和`@abstractmethod`等抽象装饰器。
```python
## Example1
from abc import ABC

class DataPreprocessor(ABC):
    @abstractmethod
    def fit(self, data: list[list[float]]) -> None:
        ...

    @abstractmethod
    def transform(self, data: list[list[float]]) -> list[list[float]]:
        ...

    def fit_transform(self, data: list[list[float]]) -> list[list[float]]:
        self.fit(data)
        return self.transform(data)
```

## 多重继承
在Python类与对象支持多重继承机制
```python
class 子类(基类A, ..., 基类N)
```
多继承下命名空间的搜索顺序可以通过`class.mro()`方法查询，搜索规则是广度优先、自左向右。
