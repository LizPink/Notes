# 绘图
当我们创建好Figure对象和其中的Axes对象之后，就可以利用Axes对象作为基本单位进行画图了。

| 函数      | 功能          | 备注  |
| ------- | ----------- | --- |
| figure  | 新增并激活一个画布对象 |     |
| subplot |             |     |
| gcf     |             |     |
| gca     |             |     |



## 折线图

| 函数或       | 功能  | 备注  |
| --------- | --- | --- |
| plot      |     |     |
| Axes.plot |     |     |
|           |     |     |
```python
# Drawing a Line Plot
ax.plot(
	**args		# args: [x],y,[str] | x1,y1,[fmt],x2,y2,[fmt2]
)
```

## 散点图

| 函数或方法        | 功能  | 备注  |
| ------------ | --- | --- |
| Axes.scatter |     |     |
```python
# Drawing a Scatter Plot
ax.scatter(
	x,			# x: List
	y			# y: List
)
```

## 柱状图

| Axes.bar |     |
| -------- | --- |
|          |     |
```python
# Drawing a Bar
ax.bar(
	x,			# x: List
	height,		# height: List
)
```
