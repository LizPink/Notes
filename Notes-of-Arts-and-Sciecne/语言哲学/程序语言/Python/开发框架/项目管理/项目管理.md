# 项目创建
应用程序的目的是存放一套直接执行的指令，用于实现期望的功能；而库文件的目的是保存一些指令以供调用。
```
                           Python Project
                                 │
                    ┌────────────┴────────────┐
                    │                         │
               Application                 Library
                    │                         │
           ┌────────┴────────┐                │
           │                 │                │
      non-package         package          package
           │                 │                │
       简单脚本          CLI / 应用         可复用库
       Web App           可安装发布         给别人 import
       课程项目               │                │
           │                 │                │
    --app --no-package   --app --package     --lib
```

| 命令                          | 用途         | 结构          |
| --------------------------- | ---------- | ----------- |
| `uv init project`           | Python App | 根目录代码       |
| `uv init --app project`     | ^          | ^           |
| `uv init --lib project`     | Python库    | src/package |
| `uv init --package project` | Python包    | ^           |

```sh
# Example1 （创建一个库项目）
## vcs: version control system
## Input[0]:
uv init --lib --build-backend uv --vcs git ml-from-scratch

## Output[0]:
ml-from-scratch/
│
├── .gitignore
├── .python-version
├── README.md
├── pyproject.toml
│
└── src/
    └── ml_from_scratch/
        └── __init__.py
```


# 文件测试
在Python项目中针对源文件的测试可以通过`pytest`包来实现。通过命令行使用`uv run pytest`指令就能运行测试文件了。具体内容会在[[Pytest]]中展开介绍。
```sh
# Example1
uv run pytest test
uv run pytest test/test_file.py
uv run pytest test/test_file.py::test_func
```

可以让VSCode识别pytest的测试文件，从而能够在VSCode中通过可视化打断点的方式运行Pytest调试。具体而言可以按住`ctrl+shift+p`选定`Python: Configure Tests`再选定pytest->test，随后VSCode就可以识别到测试文件了。
