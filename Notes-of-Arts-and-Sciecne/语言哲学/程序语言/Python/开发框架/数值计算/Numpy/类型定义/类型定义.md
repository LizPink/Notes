```python
import numpy as np
```

# NDArray
在Numpy中，最重要的一类类型就是数组类型，本节我们先来介绍一下数组类型的定义。值得注意的是在Numpy中数组的所有数据的类型必须是统一的。
## 定义方式
1. np.array
最基本的定义是通过`np.array`方法创建一个数组，或者通过其他接口创建特定的数组。
```python
# np.array:
"""
Parameters
----------
object:
	用于生成NDArray的对象。

dtype:
	用于指定数据的类型。
"""

## Example1
arr = np.array([1,2,3,4,5], dtype=np.float32)
```
2. np.zeros

| 函数          | 功能  |     |
| ----------- | --- | --- |
| np.zeros    |     |     |
| np.ones     |     |     |
| np.full     |     |     |
| np.identity |     |     |

```python
# np.zeros
# np.full
"""
Parameters
----------
shape: tuple
	用于指定数组的形状
fill_value: Any
	用于指定填充的数据值
"""

## Example1
array = np.zeros((3,4))
array = np.ones((3,4))
array = np.full((3,4), fill_value=1)
array = np.identity((3))
```

```python
# np.arange
# np.linespace

## Example1
array = np.arange(0,10,2)		# [0,2,4,6,8]
array = np.linespace(0,1,4)	# [0., 0.25, 0.5, 0.75, 1.]

```
3. np.loadtxt
除了在程序内部进行定义数组类型的方式外，我们还可以利用外部存储中的数据文件来定义数组类型，或者将已有的数组类型转化为外部存储文件。

| 函数或方法      | 功能              | 备注  |
| ---------- | --------------- | --- |
| np.save    | 存储为二进制文件 (.npy) |     |
| np.load    | 读取为二进制文件        |     |
| np.loadtxt | 读取文本文件          |     |
```python
# np.save
"""
用于将数组类型存储为.npy二进制文件。
"""
arr = np.save(
	file,	# file: str
	arr		# arr: NDArray
)

# np.load
"""
用于读取.npy二进制文件保存为数组类型。
"""
arr = np.load(
	file	# file: str
)

# np.loadtxt
arr = np.loadtxt(
	fname,				# fname: str
	delimiter=" "		# delimiter: str
)
```
4. np.random
许多时候我们可以通过`np.random.Generator`类型中的成员函数创建一个随机数组。
```python
## Example1
rng = np.random.default_rng(seed=42)

array = rng.standard_normal(size=(3,4))
array = rng.uniform(0, 1, size=(2,5))
array = rng.integers(0, 10, size=(3,))
```
## 数据结构
NDArray类型存储了如下的数据成员。其中数组是按照行优先的格式进行存储的，也就是说每一行的内存地址都是连续的。

| 属性      | 含义            | 示例     |
| ------- | ------------- | ------ |
| dtype   |               |        |
| shape   |               | (3,4)  |
| ndim    | 维度的数量         | 2      |
| size    |               | 12     |
| strides | 每个维度的单位步长（字节） | (32,8) |
