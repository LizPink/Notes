# 修改
## 元素排序
在Numpy中数组类型支持排序操作，其中排序相关的操作接口如下。

| 函数或方法           | 功能             | 备注                 |
| --------------- | -------------- | ------------------ |
| np.sort         | 对数组进行排序        | 进行拷贝排序             |
| np.sort(self)   | 对数组进行排序        | 进行原地排序             |
| np.argsort      |                | 进行拷贝排序，返回排序元素的索引   |
| np.lexsort      | 按照多个条件进行排序     | 进行拷贝排序，返回排序元素的索引   |
|                 | <              | <                  |
| np.max(self)    | 寻找数组中的最大值      |                    |
| np.argmax(self) | 寻找数组中的最大值所在的索引 | 默认是**第一个**最大值所在的索引 |
```python
# np.sort 与 np.sort(self)
np.sort(
	a				# a: ArrayLike
	axis=-1,		# axis: None | int
)

array.sort(
	axis=-1,
)
```

## 形状变换

在Numpy中，数组类型只要元素个数不变就支持在不同形状之间变换，现在我们介绍相关的语法。

| 函数或方法   | 功能  | 备注               |
| ------- | --- | ---------------- |
| reshape |     | 新的元素按照行优先的顺序进行排列 |
```python
array.reshape(
	size
)

## Example1
array = np.array([1,2,3,4,5,6])
array.reshape()
```


# 查询
## 索引查询
在Numpy中可以对数组进行索引查询。
### 查询的地址属性
对于查询结果，一般来说整数索引和切片索引都返回原类型的一个视图，而列表索引则会返回一个拷贝。
