## 元素排序
在Numpy中数组类型支持排序操作，其中排序相关的操作接口如下。

| 函数或方法           | 功能             | 备注                 |
| --------------- | -------------- | ------------------ |
| np.sort         | 对数组进行排序        | 进行拷贝排序             |
| np.sort(self)   | 对数组进行排序        | 进行原地排序             |
| np.argsort      |                | 进行拷贝排序，返回排序元素的索引   |
| np.lexsort      | 按照多个条件进行排序     | 进行拷贝排序，返回排序元素的索引   |
|                 | <              | <                  |
| np.max(self)    | 寻找数组中的最大值      |                    |
| np.argmax(self) | 寻找数组中的最大值所在的索引 | 默认是**第一个**最大值所在的索引 |
```python
# np.sort 与 np.sort(self)
np.sort(
	a				# a: ArrayLike
	axis=-1,		# axis: None | int
)

array.sort(
	axis=-1,
)
```


# 查询
## 索引查询
在Numpy中主要通过`[]`运算符对数组进行基于地址的查询。查询方式包括：整数索引、列表索引、切片索引。一般来说整数索引和切片索引都返回原类型的一个视图，而列表索引则会返回一个拷贝。而在原生Python中[[列表类型]]中只有整数索引会返回视图。


# 形状操作
在Numpy中可以对数组进行形状变换操作。从内存的视角上看，如果新数组还可以用`shape`+`strides`描述（也就是新数组的元素内存地址仍然连续）的话，形状操作就会返回一个视图，否则就会返回一个副本。

## 基本变形
最基本的形状操作是`reshape`、`newaxis`、`squeeze`
```python
# reshape

```
```python
# newaxis
# squeeze

## Example1
arr = np.arange(5)
arr_row = arr[np.newaxis, :]
arr_col = arr[:, np.newaxis]
np.squeeze(arr_row)
```

## 转置
转置是一类特殊的变形操作。转置一般都会返回一个视图。

## 展开
另外一组重要的变形操作是展开操作，常用的函数有`flatten`和`ravel`，其中flatten默认返回副本，而ravel会根据`shpe`+`strides`决定返回视图还是副本。
```python
# ravel
## Example1
arr = np.arange(12).reshape((3,4))
rav = array.ravel()
```
```python
# flatten
## Example1
arr = np.arange(12).reshape((2,3))
rav = arr.flatten()
```
