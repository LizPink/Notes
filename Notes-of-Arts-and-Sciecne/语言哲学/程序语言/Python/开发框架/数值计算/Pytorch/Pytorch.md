# 数据类型
## 张量
核心数据类型就是张量类型`Tensor`，每个张量类型在定义时负责存储数据、自身属性、计算图信息。其中计算图信息是为了后续进行反向传播计算时使用的。计算图的执行是动态的，实际运行到哪部分代码才会创建对应的计算图。

## 网络
神经网络本质上就是一系列的数学函数。根据不同的函数类型可以分为不同的网络。
### 线性层
```python
import torch.nn
network = nn.Linear(2,1)
```
线性神经网络内部存储有权重和偏置项的信息。
