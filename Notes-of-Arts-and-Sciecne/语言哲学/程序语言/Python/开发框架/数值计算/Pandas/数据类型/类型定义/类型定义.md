这一章我们来介绍==Pandas==库中重要的数据类型及其定义方法。在Pandas中重要的类型有==Index==类型、==Series==类型、==DataFrame==类型等，它们覆盖了这个库的大部分内容，所以我们首先需要了解这些类型的基本定义、基本操作、基本运算。

# Series
```python
# pd.Series
"""
Parameters
----------
data: List | Dict
	用于定义对象的数据内容。当data参数接受的是一个Dict字典类型时，字典的键会传给index参数，字典的值作为数据内容。
index: List | List[List]
```

1. pd.DataFrame
```python
# Define pd.DataFrame
"""
Parameters
----------
data: List | Dict[List]
	用于决定定义对象的数据和标签内容。当参数接受的是一个Dict[List]字典类型时，字典的键会传给columns参数，字典的值会作为对应列的数据内容。

	用于定义对象的行标签内容，当index参数接受的是一个List[List]类型时，会形成一个MultiIndex标签对象。

	用于定义对象的列标签内容，当columns参数接受的是一个List[List[str]]类型时，会形成一个MultiIndex标签对象。
```

2.1 CSV File
如果一个文件是通过分隔符进行存储的（常见于==.csv==或者==.txt==文件），那么我们可以采用==read_csv==函数来读取文件。
```python
# pd.read_csv()
"""
Parameters
----------
header: int | List[int]
	用于指定源数据文件中的标题行所在位置。如果源数据中包括了标题行，那么可以通过参数header进行指定单重或多重标题；如果没有指定会默认从0开始生成列标题。
sep: str
	用于声明分隔符文件中的分隔符形式。如果该参数收到多个字符，则会按照正则表达式的规则进行解析。如果收到参数None，则会尝试自动解析。
keep_default_na: bool
	用于决定是否将采用缺失值的默认判定方式。在Pandas中，如果源数据出现空字符串、NA、NAN等关键字符串时，会默认被视为缺失值。
na_values: List[str] | Dict[List]
	用于增加缺失值的判定方式。如果输入参数为一个嵌套列表的字典，那么可以根据不同的列增加不同的判定方式。
chunksize: None | int
"""
data_frame = pd.read_csv(
	filepath_or_buffer,			# filepath_or_buffer: str
	skiprows,					# skip_rows: int | List[int]
	header,						# header: int | List[int]
	index_col,					# index_col: int | str | List[int] | List[str]
	sep = ",",					# sep: str
	na_values,					# na_values: List[str] | Dict[List]
	nrows,						# nrows: int
	chunksize = None			# chunksize: None | int
```

### 标签等级
在==Series==和==DataFrame==类型中，标签对象可以是简单标签==Index==或复合标签==MultiIndex==类型，复合标签的内容更加复杂，但也支持更加精细的操作。下面我们来简单介绍一下有关索引对象的基本概念。索引对象具有一个==level==属性，用来表示等级关系，等级从0开始计数，等级0显示最外层或者最高层，依次向内或向下增加。

从查询的角度来说，简单与复合标签的查询语法基本一致；从运算的角度来说，带有复合标签的类型在连接时会考虑全部等级。
