# 运算符
## 算术运算

| 运算符  | 功能    | 示例            | 结果       |
| ---- | ----- | ------------- | -------- |
| `+`  | 加法    | `$((3 + 2))`  | `5`      |
| `-`  | 减法    | `$((3 - 2))`  | `1`      |
| `*`  | 乘法    | `$((3 * 2))`  | `6`      |
| `/`  | 整数除法  | `$((5 / 2))`  | `2`      |
| `%`  | 取余    | `$((5 % 2))`  | `1`      |
| `**` | 幂运算   | `$((2 ** 3))` | `8`      |
| `++` | 自增    | `((a++))`     | `a` 增加 1 |
| `--` | 自减    | `((a--))`     | `a` 减少 1 |
| `+=` | 加后赋值  | `((a += 2))`  | `a=a+2`  |
| `-=` | 减后赋值  | `((a -= 2))`  | `a=a-2`  |
| `*=` | 乘后赋值  | `((a *= 2))`  | `a=a*2`  |
| `/=` | 除后赋值  | `((a /= 2))`  | `a=a/2`  |
| `%=` | 取余后赋值 | `((a %= 2))`  | `a=a%2`  |
