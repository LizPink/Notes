数据库系统的通用数据类型主要包含如下类型：

| 类别     | 常见类型                        | 用途         |
| ------ | --------------------------- | ---------- |
| 数值型    | `INTEGER`、`FLOAT`、`DECIMAL` | 整数、小数、科学计算 |
| 字符串型   | `CHAR`、`VARCHAR`、`TEXT`     | 姓名、描述、文本   |
| 日期时间型  | `DATE`、`TIME`、`TIMESTAMP`   | 日期、时间、时间戳  |
| 布尔型    | `BOOLEAN`                   |            |
| 二进制型   | `BINARY`、`VARBINARY`、`BLOB` | 图片、文件、原始字节 |
| 半结构化数据 | `JSON`                      | 灵活结构数据     |
