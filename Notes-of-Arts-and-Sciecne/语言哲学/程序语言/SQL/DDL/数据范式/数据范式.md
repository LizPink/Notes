数据库的设计通常遵循解耦合的设计哲学，针对数据存储方式，一般而言分为三个范式。范式一关注数据原子化、范式二和范式三关注数据的依赖性。范式一指的是数据记录应当满足不可分割的性质；范式二指的是数据表应当剔除部分依赖；范式三指的是数据表应当剔除间接依赖。

其中范式三建立在范式一和范式二的基础上，进一步要求数据的独立性。例如在这个表格中，如果表格的主键为`student_id`，表格的依赖关系满足：student_id -> department_id、department_id -> department_name
```
student
(student_id, student_name, department_id, department_name)
```

那么这张表就不满足第三范式的要求，按照第三范式的要求，应当把这张表进一步拆分为如下两张表进行分别存储，以保证数据的独立性。
```
Student
(student_id, student_name, department_id)

Department
(department_id, department_name)
```
