# 工具函数
## 序列函数
在POSTGRE中使用`GENERATE_SERIES`函数可以生成一列数值或者日期序列，生成的区间是左闭右闭的区间。
```SQL
/* Example1 */
SELECT
  GENERATE_SERIES(1,10,1) AS num_sequence
  
/* Example2 */
SELECT
  GENERATE_SERIES(
    '2026-06-01'::DATE,
    '2026-06-07'::DATE,
    INTERVAL '1 Day' 
  )::DATE AS event_date
```
# 日期函数
在POSTGRE中可以使用`DATE_TRUNC`函数来获取DATE/TIMESTAMP对应的标准周度月度年度数据，该函数默认采取向下截断。
```SQL
/* Example1 */
SELECT
DATE_TRUNC('month', '2026-06-25'::DATE)	--'2026-06-01 00:00:00'::TIMESTAMP
```
# 文本函数
在POSTGRE中使用`STRING_AGG`函数可以将多行数字连成一个字符串类型。
```POSTGRE
STRING_AGG(expr, delimiter)
```
