# 类类型的生命
类对象的生命周期就是这个对象可以被合法使用的时间区间，一般为创建->调用->销毁三个阶段。在创建过程大致发生了如下事情：内存分配->初始化数据成员->执行构造函数。
## 构造函数
构造是对象生命周期开始的标志，构造是按照数据成员在类中的声明顺序进行的。构造函数具有如下特性：（1）在执行构造函数函数体前，类的所有数据成员已经初始化。
```cpp
/* 构造函数 */
类名(参数列表):初始化列表
{
	函数体
}

// Example1
class Student {
private:
	int age = 0;	
public:
	// 构造函数：
	Student(int new_age):
		age{new_age}
	{
		std::cout << "Call Class Initializer..." << std::endl;
	}
}
```

### 构造函数委托
```cpp
class Student {
private:
    std::string name;
    int age;

public:
    Student();
    explicit Student(int age);
    Student(std::string name);
    Student(std::string name, int age);
};

Student::Student(std::string name, int age)
    : name{name}, age{age} {
}
Student::Student()
    : Student{"unknown", 0} {
}
Student::Student(int age)
    : Student("unknown", age) {
}
Student::Student(std::string name)
    : Student(name, 0) {
}
```

## 析构函数
析构是类对象生命周期结束的标志，析构会按照对象成员的声明逆序进行的。析构函数具有如下特性：（1）不具有返回类型、不接收参数、不支持函数重载；（2）在执行析构函数函数体时，类的所有数据成员还未析构。
```cpp
/* 析构函数 */
~类名(参数列表)
{
	函数体
}

// Example1
class Student {
public:
	// 析构函数：
	~Student()
	{
		std::cout << "Call Destruction Function ..." << this << std::endl;
	}
}
```

# 经验之谈
## 经验之谈
### Rule of Five
> 如果一个类需要自行定义析构函数、复制构造函数或复制赋值运算符、移动构造函数或者移动运算符中的任意一个，通常也应该认真考虑另外四个。

### Rule of Zero
> 外层类尽量不要直接管理原始资源，而是让成熟的内部成员类型管理。

***函数多态***
> 不要在构造函数或析构函数中依赖虚函数执行派生类特有行为。
