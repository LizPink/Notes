
## 访问权限
子类可以继承基类的数据成员、函数成员。子类可以访问基类的公有成员，不能访问基类的私有成员。

|基类成员原权限|`public` 继承后|`protected` 继承后|`private` 继承后|
|---|--:|--:|--:|
|`public`|`public`|`protected`|`private`|
|`protected`|`protected`|`protected`|`private`|
|`private`|仍不能由派生类直接访问|仍不能由派生类直接访问|仍不能由派生类直接访问|

## 构造函数
```cpp
// Example1
class Base {
public:
    explicit Base(int value) {
    }
};

class Derived : public Base {
private:
    int number;

public:
    Derived(int base_value, int number)
        : Base(base_value),
          number(number) {
    }
};

// Example2
class Base1 {};
class Base2 {};
class Member1 {};
class Member2 {};
class Derived : public Base1, public Base2 {
private:
    Member1 first;
    Member2 second;
};
```

# 类继承的特性
## 类型转换
子类对象可以被当成基类对象看待，这种机制叫做向上转换。经过向上转换得到的对象，仍然保存有完整派生对象的信息，但通常默认只访问基类的数据和方法。但是可以通过虚函数机制让向上转换的类型访问子类的数据和方法。
## 继承机制

| 机制   | 发生范围    | 是否要求同名 | 参数列表要求 | 是否需要 `virtual` | 核心作用             |
| ---- | ------- | -----: | ------ | -------------: | ---------------- |
| 函数重载 | 同一个作用域内 |      是 | 必须不同   |              否 | 根据实参选择不同函数       |
| 成员隐藏 | 父类与子类之间 |      是 | 无论是否相同 |              否 | 子类中的成员隐藏了父类同名成员  |
| 函数重写 | 父类与子类之间 |      是 | 基本必须相同 |              是 | 通过基类指针或引用实现运行时多态 |
子类对象的函数会隐藏基类对象的同名成员，如果想通过子类访问基类同名成员，必须在类定义时使用`using`关键字指定基类作用域的成员，或者在调用时指定基类的作用域的成员。
