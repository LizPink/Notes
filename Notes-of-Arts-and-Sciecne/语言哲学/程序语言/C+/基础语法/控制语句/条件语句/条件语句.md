# Switch Clause
switch条件语句的基础语法如下。其中switch变量必须是整数或者枚举类型，每个case必须对应一个编译期常量。switch分支语句默认是逐个case依次向下匹配的（贯穿），因此想要停止贯穿需要在代码块中加入break中断语句。在C++14标准之后switch语句也支持了初始化局内变量的语法。
```cpp
// Exmaple1
auto x = getState();
switch(x)
{
case State::s0:
	std::println("zero");
	break;

case State::s1:
	std::println("one");
	break;
	
default :
	std::println("{}}", x);
}

```
```cpp
// Example2
switch (auto x = getState(); x)
{
	case State::s0:
	{
		std::println("zero");
		break;
	}
	case State::s1:
	{
		std::println("one");
	    break;	
	}
	default:
	{	std::println("{}", x);	}
}
```
