# For Loop
这一章我们介绍`for`循环语句，该循环语句有两种主要形式。其中Range-Based循环仅要求变量类型具有`begin`和`end`属性，并且在该循环中变量element默认复制Itreable_Type中的元素类型，通常也可以修饰为引用类型优化内存。
```C++
/* Domain-Based For Loop */
for (start;stop;step)
{
	...
}


/* Range-Based For Loop */
for (auto element : Iterable_Type)		// Better: auto &element
{
	...
}
```
