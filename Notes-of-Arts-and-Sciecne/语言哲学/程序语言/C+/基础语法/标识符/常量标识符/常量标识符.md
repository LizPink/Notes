# 限定符const
## 普通函数的const标识符
以只读权限访问传入的参数.
```cpp
// Example1
void print(const Student& s)
{
	std::cout << s.get_age() << std::endl;
}
```


## 类函数的const标识符
不允许修改类对象的数据成员.
```cpp
/* const:只读方式访问类对象 */
返回类型 函数名(参数列表) const
{
	函数体
}

// 等效理解形式
返回类型 函数名(const 类名* this, 参数列表)
{
	函数体
}

```
## 类对象的const标识符
```cpp
/* const:只读方式创建类对象 */
// Example1 
const Student student{20};
```
