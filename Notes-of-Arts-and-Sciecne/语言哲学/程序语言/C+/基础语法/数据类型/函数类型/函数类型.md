# 函数的定义
```cpp
/* 函数的声明 */
返回类型 函数名(参数列表);

/* 函数的定义 */
返回类型 函数名(参数列表){
	函数体
}

// Example1 Add Function
int add(int, int);
int add(int a, int b){
	return a+b
}
```
## 函数的类型
每一个函数都有自己的子类型属性，在C++中根据返回类型和参数类型将不同的函数划分为不同的子类型。划分函数子类型的一个作用是方便定义函数指针，如同数组一样，函数作为右值的时候一般会退化为函数所在的内存地址。
```cpp
/* Type int(int, int) */
int add(int, int);

```
