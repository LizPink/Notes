# 函数的定义
在C++中定义了一系列特殊的类类型`functional::function<函数类型>`用于表示函数的概念，函数把包括普通函数、类函数、指向这些函数的指针。
## 抽象函数
```cpp
#include <functional>
// Example1
std::function<int(int, int)> func;
```

## 普通函数
普通函数类型是最基本的函数，其具体类型由返回值和参数列表确定。如同数组一样，普通函数类型作为右值的时候一般会退化为函数执行入口的内存地址。
```cpp
/* 普通函数的声明 */
返回类型 函数名(参数列表);

/* 普通函数的定义 */
返回类型 函数名(参数列表){
	函数体
}

// Example1 Add Function
int add(int, int);
int add(int a, int b){
	return a+b;
}
```

## 类函数
类函数是通过类类型来实现的函数，本质上是一类重载了`()`运算符的类。实现包括隐式实现（匿名类的定义）和显式实现（普通类的定义）。
```cpp
/* 匿名函数的定义 */
[capture](parameters){
    function_body
}

//Example1
threshold = 10
[threshold](int x){
	return x>threshold;
}
```
```cpp
class 函数类名{
	返回类型 operation()(参数列表){
		函数体
	}
}

```


# 函数的重载
函数重载的充分必要条件是函数签名支持重载（相同作用域下函数名相同且参数列表不同）。
