# 函数的定义
在C++中定义了一系列特殊的类类型`functional::function<函数类型>`用于表示函数的概念，函数把包括普通函数、类函数、指向这些函数的指针。
## 普通函数
普通函数类型是最基本的函数，其具体类型由返回值和参数列表确定。如同数组一样，普通函数类型作为右值的时候一般会退化为函数执行入口的内存地址。
```cpp
/* 普通函数的声明 */
返回类型 函数名(参数列表);

/* 普通函数的定义 */
返回类型 函数名(参数列表){
	函数体
}

// Example1 Add Function
int add(int, int);
int add(int a, int b){
	return a+b;
}
```

## 主函数
主函数是一个特殊的普通函数。主函数的特殊性在于其作为程序初始入口，其参数具有特殊含义。主函数的一般定义语法如下。其中`argc`表示命令行传递的参数个数，`argv`表示命令行传递的参数数组，`env`表示命令行的环境变量数组。一般而言可执行程序本身的文件路径会被计为第一个参数。
```cpp
int main();
int main(int argc, char* argv[]);
int main(int argc, char* argv[], char* env[]);
```
```cpp
// Example1
int main(int argc, char* argv[])
{
	return 0;
}

// Example2
int main(int argc, char* argv[], char* env[])
{
	return 0;
}


```

## 类函数
类函数是通过类类型来实现的函数，本质上是一类重载了`()`运算符的类。实现包括隐式实现（匿名类的定义）和显式实现（普通类的定义）。
```cpp
/* 匿名函数的定义 */
[capture](parameters){
    function_body
}

//Example1
threshold = 10
[threshold](int x){
	return x>threshold;
}
```
```cpp
class 函数类名{
	返回类型 operation()(参数列表){
		函数体
	}
}

```

# 函数的重载
函数重载的充分必要条件是函数签名支持重载（相同作用域下函数名相同且参数列表不同），这里参数列表的不同是指列表的顺序、参数类型不同。注意不同的类型，可能对应同一个参数类型，这是C++编译器最恶心的地方。

举反例`const int a`或`int const a`和`int a`在编译器看来是同一个参数类型，因为这里的`const`只是限定了参数变量在函数体内部的访问权限，并没有修改传入变量的类型范围；另一个反例是`int* p`和`int* const p`也是同一个参数类型，因为前者和后者均是指向整型的指针，这里的`const`只是限定了函数体对变量p的访问权限。

举正例`const int a`或`int const* a`和`int* a`在编译器看来是不同的参数类型，因为前者指针只能指向整型常量，而后者指针可以指向整型常量和变量，接收类型的范围更广；另一个反例是`int& a`和`const int& a`或`int const& a`也是不同的参数类型。
