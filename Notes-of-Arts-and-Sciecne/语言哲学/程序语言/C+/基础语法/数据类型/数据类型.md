# 类型基本概念
类型也称为变量，在C++中变量与变量标识符的本质就是内存。

### 变量定义
变量的定义按照完成程度可以分为声明与声明且初始化。
```cpp
// Example1
int num;
int num{0};
```

### 常量定义
在C++中一个量默认是变量，当然也支持常量定义，从某种意义上说常量也是一种特殊的变量。常量分为编译时常量和运行时常量，常量必须声明初始化，并且不能再修改。此外编译时常量在编译期就需要确认取值，运行时常量只需要在运行时才确定取值。编译时常量的作用主要是用于优化代码提高效率，运行时常量主要作用是用于保护数据不被修改，确保代码逻辑安全。
```cpp
// Example1 编译时常量
constexpr int num{100};

// Example2 运行时常量
const int num1{0};
const int num2{num1+100};
```



### 变量的范围
变量的范围的主要是指变量的作用域、生命周期。变量可以根据作用域分为全局变量、局部变量。在C++中全局变量指的是单个编译文件内**不在任何代码块、函数、类、模板内定义的变量**，例如在文件主函数之前声明或定义好的变量。
```cpp
// Example1 全局变量
int num{0};
int main()
{
	return 0;
}
```
在多个作用域中可以定义相同名字的变量，在C++中默认会自内向外依次覆盖各名字。


# 类型资源管理
资源的所有权指的是变量标识符对于某个资源的所有权。在C++中变量标识符本质上是独立的内存，用来存储特定类型的资源。
## 类型传递
在C++中变量传递行为默认是值传递语义。要确定具体类型的传递行为，必须参考类型的传递构造函数和传递运算符的具体定义。
