在C++中字符串字面量是通过常量字符`const char`或者常量字符数组`const char* []`的方式实现的. 除此之外在C++标准库中有更加高级的`String`类型可以使用，这是本章介绍的重点内容。
```cpp
import std;
```

# 字符串的定义
```cpp
/* Example1 */
std::string s1{};
std::string s2{"Hello World"};
std::string s3{s2};
```

| stod         | 字符串转换为双精度分数 |

| to_string    |             |
| **字符串彼此间转换** |             |
