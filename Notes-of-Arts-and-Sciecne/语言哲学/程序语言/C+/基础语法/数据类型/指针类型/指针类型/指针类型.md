# 指针的定义

## 智能指针
智能指针是借助类的机制来管理动态对象的指针类型。智能指针有`unique_ptr<T>`、`shared_ptr<T>`、`weak_ptr<T>`三种主要类型。
```cpp
/* 智能指针的定义 */
#include<memory>

// Example1
auto p = std::make_unique<T>(params);

// Example2
auto p = std::make_shared<T>(params)

// Example3
auto p = std::make_shared<T>(params)
std::weak_ptr<T> w = p;
```
其中弱指针类型是非拥有类型的指针，经常搭配共享指针使用，因为弱指针不会增加共享指针的共享计数。弱指针的作用仅仅是参与观察，而不对目标对象进行管理。
# 指针的操作
## 智能指针

| 操作          | 返回地址 | 放弃所有权 | 释放当前资源 |
| ----------- | ---: | ----: | -----: |
| `get()`     |    是 |     否 |      否 |
| `reset()`   |    否 |     是 |      是 |
| `release()` |    是 |     是 |      否 |
