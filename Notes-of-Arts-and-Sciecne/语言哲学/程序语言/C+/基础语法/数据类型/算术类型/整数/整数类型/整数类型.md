整数类型是C++中的一类基础且重要的类型。在C++中整数类型还有很多子类型。其中`size_t`类型是表示大小的元类型，在不同硬件环境下有所不同，但无论如何它都能表达当前环境中任何对象的内存大小。

| 类型名                | 内存大小    | 表示范围                  |
| ------------------ | ------- | --------------------- |
| *有符号整型*            | <       | <                     |
| int                | 4 Byte  | $-2^{31}\sim2^{31}-1$ |
| long long          | 8 Byte  | $2^{64}$              |
| *无符号整型*            | <       | <                     |
| unsigned int       | 4 Bytes |                       |
| unsigned long long | 8 Bytes |                       |
| *固定宽度整型*           | <       | <                     |
| int32_t            | 4 Byte  |                       |
| int64_t            | 8 Byte  |                       |
| uint32_t           | 4 Byte  |                       |
| uint64_t           | 8 Byte  |                       |
| *语义整型*             | <       | <                     |
| size_t             | x Byte  | 通用表示大小的无符号整型          |
