# 内存管理
鉴于C++是一门mid level的语言，在C++中我们需要介绍一些有关内存管理的知识。硬件厂商一般会将内存划分为栈区、堆区和其他区域等等。在C++程序加载时，操作系统会为程序分配内存资源，其中主要的内存资源包括栈区(Stack)和堆区 (Heap)内存。

通常而言不是通过`new`关键字直接定义的局部变量都会被分配到栈区内存，特别注意指针类型，无论是否指向一个`new`关键字修饰的类型，都会被分配到栈区内存中。

当一段程序结束时，对应栈区中的数据会被自动释放，而堆区中的数据不会自动释放。这意味着如果此时定义了一个指针类型，当指针所在的内存被释放时，指针指向的数据可能仍然停留在堆区中，造成程序内存泄漏问题。所以指针类型经常需要在生命周期结束前主动释放对应堆区的内存。
## 类型定义
在类型定义的时候，需要区分初始化和赋值的概念，因为C++编译器会将初始化和赋值提供两种不同的处理逻辑，而有些时候代码逻辑会将初始化写成赋值，造成多余的初始化指令调用。因此有时候合理地处理初始化和赋值的关系可以减少不必要的操作。我们需要介绍C++中的一类初始化机制-列表初始化。
## 数据传递
在C++中进行赋值，无论是等号赋值还是参数传递，一般默认为复制逻辑。也就是说当编译器在解析赋值语句或者函数的参数传递语句的时候，会额外开辟一块地址存储相同的数据内容。这种特性会增加内存占用，所以在C++中引用和指针逻辑在内存优化中就显得相当重要了。

# 模块引用
本章我们介绍C++中的一些标准模块，这些模块拓展了C++的语法功能，就类似于Python语言中的拓展模块。要引入一个标准模块，你需要在`main`文件的最开始引入这些模块。
```c++
/* Introduce a module */
#include <name_of_module>

// Example
#include <iostream>
```
当我们在代码文件中引入了另外一个模块，并且想要使用这个模块中的内容，我们就需要使用模块对应的命名空间名称和`::`域解析操作符来使用他们的内容。
```c++
#include <iostream>

int main()
{
	a = std::string("abcd");
	std::cout << a;
	
	return 0;
}
```
