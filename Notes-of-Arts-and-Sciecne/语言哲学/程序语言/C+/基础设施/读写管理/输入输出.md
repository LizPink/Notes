# 标准读写对象
在C++中预先定义了两个标准读写对象`std::cin`和`std::cout`用于支持用户的读写行为。两个对象分别关联了自己的流内存缓冲区`stream buffer`，读写行为通过内存缓冲区与外部设备进行交互。
## 读操作
对于cin对象可以通过`>>`进行读缓冲操作。在执行读缓冲操作时，默认跳过空白字符，读取非空白字符。如果某时刻缓冲区没有有效内容，就会中断并等待用户输入；否则则会读取。
# 内存缓冲区
在C++中可以通过`std::cin.rdbuf()`访问到输入流对象的内存缓冲区，该方法返回输入流对象的指针。通过缓冲区对象，可以借助`in_avail()`来访问输入流缓冲区中存储的字符数量。
```cpp
// Stream Buffer
std::cin.rdbuf();

// Stream Buffer Available Characters
std::cin.rdbuf()->in_avail();
```
