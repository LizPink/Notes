# 主站-数据分析
## 数据指标
数据关注点主要关注：1、用户层面的数据。包括日活、月活、新增用户数、用户1日/3日/7日留存、用户在线时长、人均播放量2、内容维度的数据。包括视频播放量、有效播放率、点赞率、评论率、分享率、收藏率。3、业务方面的数据。活动参与率、商品交易总额GMV、投资回报率ROI、广告投放效果。

## 异动归因
### 确认异动
（1）指标的统计口径是否发生变化
（2）指标的数据是否及时更新
（3）与历史正常波动水平进行比较
### 纵向拆解
指标拆解从纵向展开分析，适合分析规模与效率的变化：
（1）DAU = 新增用户活跃 + 老用户活跃
（2）播放量 = DAUx人均播放次数
（3）总播放时长 = DAU x 人均播放时长（人均播放次数 x 单次平均时长）
（4）GMV = 访问用户数 x 支付转化率 x 客单价
（5）广告收入 = DAU x 人均曝光次数 x CPM

## 因果分析
### 混淆变量
#### 如何判断混淆变量？
混淆变量应当是同其他变量一样具体的、可以测量的变量，而不是某种抽象的因素。因为抽象的因素很难具体衡量其因果作用，而且一种抽象因素可以有多种具体变量作为体现。因此考虑因果效用，必须以可定义可测量的变量作为基本单位。

### AB实验
#### 样本量计算
样本量的计算取决于：（1）显著性水平与检验功效；（2）最小的可检测效应MDE；（3）统计量的标准误。

#### 样本量达不到应该怎么办？
如果说样本量达不到的情况下，可以考虑：（1）延长实验周期；（2）调整显著性水平与检验功效；（3）调整最小可检测效应。
