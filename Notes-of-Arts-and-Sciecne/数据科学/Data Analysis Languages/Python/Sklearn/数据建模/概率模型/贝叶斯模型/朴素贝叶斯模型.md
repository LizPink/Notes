这一章我们介绍朴素贝叶斯模型，该模型是一个常见的分类模型。本章我们将会频繁用到`sklearn.naive_beyes`模块。
# 模型设定
朴素贝叶斯在训练模型的时候需要用到标签数据，因此属于监督学习模型。同时与[[数据科学/Data Analysis Languages/Python/Sklearn/数据建模/线性模型/线性模型]]中的Losigtic该模型一样，预测的是样本属于各个类别的概率，因此属于概率模型。根据不同的特征类型有不同的分类器变体，常见的模型有GaussianNaiveBayes、MultinomialNaiveBayes、BernoulliNaiveBayes三类这分类，分别针对连续类型特征、计数类型特征、二值类型特征。
### 模型假设
该模型假设该给定类别标签的情况下，各个特征之间是相互独立的，也就是说各个特征之间是条件独立的。这是一个很强的假设。

# 模型训练
在模型输出阶段，由于该模型属于概率模型，因此可以输出样本对应类别的概率。
```python
# naive_bayes.Gaussian
model = naive_bayes.GaussianNB()

## model output
model.classes_					# 预测类别
model.predict_proba(X_test)
```
