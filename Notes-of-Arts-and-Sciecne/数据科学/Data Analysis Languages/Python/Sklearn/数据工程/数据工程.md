## 通用工具
这一章我们介绍一些通用的数据分析工具。首先我们先介绍可以统一对不同类型的数据列做不同处理的工具，在sklearn中有ColumnTransformer列转换器类型专门提供这类接口。列转换器ColumnTransformer类型的主要用法是对不同的数据列采用不同的预处理方法，然后再把各个单独的处理结果拼接成最终处理结果。

| 函数或方法                                                      | 功能  | 备注  |
| ---------------------------------------------------------- | --- | --- |
| sklearn.compose.ColumnTransformer.fit_transform -> NDArray |     |     |
```python
# Compose.ColumnTransformer
preprocessor = skleran.compose.ColumnTransformer(
	transformers,			# transformers: List[tuples]
	remainder = "Drop"		# remainder: ["drop", "passthrough"]
)

## Example1
## --------
X = pd.DataFrame({  
"age": [20, 35, 28, 42],  
"income": [5000, 12000, 8000, 20000],  
"city": ["北京", "上海", "广州", "北京"],  
"gender": ["男", "女", "女", "男"]  
})

preprocessor = skleran.compose.ColumnTransformer([
	("num", preprocessing.StandardScaler(), ["age", "income"]),	# ["age", "income"] == [0,1]
	("cat", preprocessing.OntHotEncoder(), ["city", "gender"])	# ["city", "gender"] == [2,3]
])

X_transformed = preprocessor.fit_transform(X)
```
