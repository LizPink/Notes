## 重复删减
在Pandas中，类型==Series==和==DataFrame==支持通过==unique==与==drop_duplicate==方法去除重复的元素。

| 函数或方法                                          | 含义      |              备注               |
| :--------------------------------------------- | :------ | :---------------------------: |
| pd.Series.unique(self) -> NDArray              | 对元素进行去重 | 该方法只能应用于==Series==类型，返回一个拷贝类型 |
| pd.drop_duplicate(self) -> Series \| DataFrame | 对元素进行去重 |                               |
其中需要注意的是，方法==.unique()==返回的数据是无序的，因此有排序需求的话需要重新排序.
```python
# Series.unique
result = series.unique()
result = data_frame["column_one"].unique()

# drop_diplicate
data_frame.drop_diplicate(
	subset = data_frame.columns,		# subset: List[str]
	keep = "first",						# keep: ["first", "last", False]
	inplace = False
)
```

## 元素排序
在Pandas中，类型Series和DataFrame支持通过==.sort_index==与==.sort_values==方法对元素进行排序，如果需要计算排名名次则可以通过==.rank==方法实现。

| 函数或方法                | 含义        | 备注  |
| :------------------- | :-------- | :-: |
| pd.sort_index(self)  | 对行列索引进行排序 |     |
| pd.sort_values(self) | 对数据数值进行排序 |     |
其中在==.sort_index()==和==.sort_values()==排序中，排序的
```python
# sort_index()
series.sort_index(
	axis = "index",
	level = 0			# level: int | List[int]
	ascending = True,	# ascending: bool = True
	inplace = False		# inplace: bool = False
)
data_frame.sort_index(
	axis = "index",		# index: ["index", "columns"]
	level = 0			# level: int | List[int]
	ascending = True,	# ascending: bool = True
	inplace = False
)

# sort_values()
## sorting values for Series
series.sort_values(
	ascending = True,
	na_position = "last",	# na_position : ["first", "last"] = "last"
	inplace = False
)
## sorting values for DataFrame
data_frame.sort_values(
	by = ...				# by: list[str]
	ascending = True,		# ascending: bool | list[bool] = True
	na_position = "last",
	inplace = True
)
```
其中在==.rank()==方法中，排序方法参数==method==的含义解释见下表.

| 参数选项    | 含义                        |
| ------- | ------------------------- |
| min     | 对于排名相同的元素，取其中的最小排名        |
| average | 对于排名相同的元素，取其中的平均排名        |
| max     | 对于排名相同的元素，取其中的最大排名        |
| first   | 对于排名相同的元素，按照出现次序排名        |
| dense   | 对于排名相同的元素，取其中的最小排名，并且连续排名 |
```python
data_frame.rank(
	axis = "rows",		# axis: ["rows", "columns"]
	method = "average",	# method: ["min", "average", "max", "first", "dense"]
	ascending = True
)
```

## 索引查询
这一节我们介绍索引查询的相关知识，索引和切片机制可以通过==[ ]==运算符、==.loc[]==运算符、==.iloc[]==运算符实现，该机制支持Series和DataFrame类型查找满足特定条件要求的元素，下面我们就来一一介绍。

首先是介绍Series类型的索引语法。类型Series只有行索引，其中==loc==用来表示标签行索引，==iloc==用来表示地址行索引，==[ ]==既能表示标签行索引也能表示地址行索引，取决于具体语法形式。
```python
# Indexing for Series
## 标签行索引
"""
根据Series对象的标签，查找对应的元素。
[1]如果采用切片形式索引，则是闭区间，且按照切片顺序索引！
[2]如果采用列表或者切片索引，则返回被索引对象类型相同的类型，否则可能返回退化类型。
"""
series[value_index]				# value_index: int | List[int] | str | List[str] | Slice[str]
series.loc[value_index]			# value_index: int | List[int] | str | List[str] | Slice

## 整数行索引
"""
根据Series对象的地址，查找对应的元素。
[1]如果采用切片形式索引，则是开区间，且按照切片顺序索引！
[2]如果采用列表或者切片索引，则返回被索引对象类型相同的类型，否则可能返回退化类型。
"""
series[address_index]			# address_index: Slice[int]
series.iloc[address_index]		# value_index: int | List[int] | Slice
```

其次介绍DataFrame类型的索引语法。
```python
# Indexing for DataFrame
## 列索引
"""
根据DataFrame对象的列标签，查找对应的列。
[1]如果根据列表索引，则返回被索引对象类型相同的类型，否则可能返回退化类型。
"""
data_frame[value_index]			# value_index: str | List[str]


## 行索引
### 标签行索引
"""
根据DataFrame对象的行标签，查找对应的行。
[1]如果采用切片形式索引，则是闭区间，且按照切片顺序索引！
[2]如果根据列表索引，则返回被索引对象类型相同的类型，否则可能返回退化类型。
"""
data_frame[value_index]					# value_index: Slice[str]
data_frame.loc[value_index]				# index: int | str | List[int] | List[str] | Slice
### 地址行索引
"""
根据DataFrame对象的行地址，查找对应的行。
[1]如果采用切片形式索引，则是开区间，且按照切片顺序索引！
[2]如果根据列表索引，则返回被索引对象类型相同的类型，否则可能返回退化类型。
"""
data_frame[address_index]				# index: Slice[int]
data_frame.iloc[address_index]			# address_index: int | List[int] | Slice


## 行列索引
"""
根据DataFrame对象的行列标签|行列地址，查找对应的行列。
[1]如果采用切片形式索引则是闭区间，采用切片形式索引则是开区间，且按照切片顺序索引！
[2]如果根据列表索引，则返回被索引对象类型相同的类型，否则可能返回退化类型。
"""
data_frame.loc[value_index, value_index]
data_frame.iloc[address_index, address_index]
```
### 查询结果的地址
索引的返回对象的地址属性是怎么样的呢，如果索引时不包含切片，则通常返回一个类型视图；如果索引时包含了切片，则通常情况会返回一个类型拷贝。

## 其他查询
这一节我们来讲其他的查询机制。类型Series和DataFrame可以通过==.isin()==方法利查找是否具有目标容器中的元素；可以通过==.get_indexer()==方法，查询任意一组标签在给定标签（元素必须唯一）中的整数位置。

| 函数或方法                                 | 功能              | 备注                               |
| ------------------------------------- | --------------- | -------------------------------- |
| .isin() -> Series \| DataFrame        | 判断元素是否位于某个元素集合中 | 该方法在==DataFrame==类型使用时会涉及到索引对齐问题 |
| pd.Index.get_indexer(self) -> NDArray |                 |                                  |
```python
# isin() for Series
series.isin(
	values		# values: List | Series
)

# isin() for  DataFrame
"""
Parameters
----------
values: List, Series, DataFrame
	如果输入的是List，则只判断元素是否在List内；如果输入的是Series或者DataFrame，则还要确保行列索引能够匹配上.
"""
dataframe.isin(
	values						# values: List | Series | DataFrame
)
```
```python
# pd.Index.get_indexer
"""
调用该方法前，必须确保索引对象的元素是唯一的！

Parameters
----------

"""
index.get_indexer(
	target = [1,2,3,4,5]		# target: List | Series
)
```
