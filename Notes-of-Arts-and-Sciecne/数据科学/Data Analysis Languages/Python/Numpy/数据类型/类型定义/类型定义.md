```python
# np.array

```

## 数据读写
除了在程序内部进行定义数组类型的方式外，我们还可以利用外部存储中的数据文件来定义数组类型，或者将已有的数组类型转化为外部存储文件。

| 函数或方法      | 功能             | 备注  |
| ---------- | -------------- | --- |
| np.save    | 读取二进制文件 (.npy) |     |
| np.load    |                |     |
| np.loadtxt | 读取文本文件 (.txt)  |     |
```python
# np.save
"""
用于将数组类型存储为.npy二进制文件。
"""
arr = np.save(
	file,	# file: str
	arr		# arr: NDArray
)

# np.load
"""
用于读取.npy二进制文件保存为数组类型。
"""
arr = np.load(
	file	# file: str
)

# np.loadtxt
arr = np.loadtxt(
	fname,				# fname: str
	delimiter=" "		# delimiter: str
)
```
