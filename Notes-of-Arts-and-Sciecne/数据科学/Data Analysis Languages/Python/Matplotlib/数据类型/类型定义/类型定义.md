这一部分我们来介绍Matplotlib中常见的类型，他们构成了这个库的绘图逻辑。那么在Matplotlib中，整个绘画过程被抽象成为了==Figure==、==Axes==、==Axis==、==Artist==几个基本类型，分别对应不同的绘画过程。其中Figure类型表示了一个画布。而Axes类型代表了这块画布上的一个绘图区域，一个画布上会有一个或者多个绘图区域。而==Axis==和==Artisi==类型分别代表了每个绘图区域的坐标轴和绘画风格。这些类型组成了一个绘图的基本结构，下面我们就来一一介绍。
# 画布类型
## 类型定义

| 函数或方法                                        | 功能  | 备注  |
| -------------------------------------------- | --- | --- |
| plt.figure() -> Figure                       |     |     |
| plt.subplots -> tuple(Figure, NDArray[Axes]) |     |     |
```python
# Define Figure
## plt.figure
fig = plt.figure()

## plt.subplots
fig, axes = plt.subplots(
	nrows,		# nrows: int
	ncols		# ncols: int
)
```
## 类型析构
在使用完一张画布之后，应该及时对画布类型进行析构，否则该画布类型仍有可能留在内存中，占用多余空间。
```python
# Resolve Figure
plt.close(
	fig		fig: Figure
)
```
