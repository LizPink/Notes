# 元素运算
在==Numpy==库中，运算函数一般是逐个元素进行的。在==Pandas==库中我们继承并拓展了这样的思想，类型==Series==和==DataFrame==支持逐列或者逐个元素的运算.

| 函数或方法                    | 功能                        | 备注                 |
| ------------------------ | ------------------------- | ------------------ |
| pd.Index.map(self)       |                           |                    |
| pd.Series.map(self)      | 在==Series==类型中实现*逐个*运算    |                    |
| pd.Series.apply(self)    | 在==Series==类型中实现*逐个*运算    | 相对于map可以支持更复杂的对应逻辑 |
| pd.DataFrame.map(self)   | 在==DataFrame==类型中实现*逐个*运算 |                    |
| pd.DataFrame.apply(self) | 在==DataFrame==类型中实现*逐列*运算 |                    |
```python
# pd.Index.map
"""
Parameters
----------
func: Dict | Function
	如果输入参数为Dict字典类型，匹配不上的话会返回NaN类型.
"""
index.map(
	mapper = None	# func: Dict | Function
)


# pd.Series.map
"""
Parameters
----------
func: Dict | Function
	如果输入参数为Dict字典类型，匹配不上的话会返回NaN类型.
"""
series.map(
	func = None		# func: Dict | Function
)


# pd.DataFrame.map
"""
用于实现逐个数据的运算

Parameters
----------
func: Function
"""
data_frame.map(
	func = None		# func: Function
)

# pd.DataFrame.apply
"""
用于实现逐列数据的运算

Parameters
----------
func: Function
"""
data_frame.apply(
	func = None,	# func: Function 
	axis = 0,		# axis: [0,1]
)
```

## 聚合运算
在实际的数据分析应用过程中，经常会遇到需要进行分组统计的情况，库Pandas为我们提供了一些进行分组统计的方法。整个聚合计算的实现方法主要分为三部分：split、apply、combine。在第一个阶段先是根据标签进行==groupby==分组，然后对于每一组对象通过==apply==方法进行分组统计，最后通过==concat==连接数据汇总计算结果。

| 函数或方法                                                  | 功能         | 备注  |
| ------------------------------------------------------ | ---------- | --- |
| pd.groupby(self) --> SeriesGroupBy \| DataFrameGroupBy | 提供聚合统计计算   |     |
| pd.agg(self)                                           |            |     |
```python
# pd.Series.gropuby
"""
Parameters
----------
by: List | Series | Dict | Function
	用于决定分组的依据。如果输入的是一个List或者Series对象，则会先根据标签对齐再根据内容分组；如果输入的是一个dict对象或者Function对象，则均会作用于索引的值，根据结果进行分组。
level: 
	用于决定分组的依据。
"""
series.groupby(
	by,					# by: List | Series | Dict | Fcuntion
	level,				# by: str | List[str] | int | List[int]
	group_keys=True,
	dropna=True
)

# pd.DataFrame.groupby
"""
Parameters
----------
by: str | List[str] | List | Series | Dict | Function
	用于决定分组的依据。如果输入的是str列名或者List[str]列名列表，则会优先根据对应列的取值进行分组；如果输入的是一个List或者Series对象，则会先根据标签对齐再根据内容分组；如果输入的是一个dict对象或者Function对象，则均会作用于索引的值，根据结果进行分组。
level: 
	用于决定分组的依据。
"""
data_frame.groupby(
	by,					# by: str | List[str] | List | Series | Dict | Function
	level,				# level: str | List[str] | int | List[int]
	group_keys=True,
	dropna=True
)

```
其中==.agg==方法默认会调用Pandas自己的函数进行计算，此外也可以通过传递函数对象的方式调用自定义或者其他库的函数。
```python
data_frame.agg(
	func:				# func: AggFuncType
	as_index = True
)
```

# 连接运算
在Pandas中，有许多接口为数据类型之间的连接组合提供了方便，下面我们一一进行介绍。

| 函数或方法            | 功能            | 备注  |
| ---------------- | ------------- | --- |
| pd.join(self)    |               |     |
| pd.merge         | 提供关系型数据库的形式连接 |     |
| pd.concat        | 按照轴的方向连接      |     |
| pd.combine(self) | 对齐合并缺失数据      |     |
```python
# pd.join
"""
Parameters
----------
on: str | List[str]
	用于指定左边对象的匹配列。注意该参数不会改变右对象的匹配列，整个方法只能匹配右对象的索引列。
"""
data_frame.join(
	other,			# other: Series | DataFrame | List[Series | DataFrame]
	on = None,
	how = "left",
	lsuffix = "",
	rsuffix = ""
)

# pd.merge
"""
Parameters
----------
suffixes: Tuple[str]
	用于处理重叠列的命名方式。
"""
pd.merge(
	left,					# left: Series | DataFrame
	right,					# right: Series | DataFrame
	on = ...,				# on: List[str]
	left_on,
	left_index = False,
	right_on,
	right_index = False,
	how = "inner",			# how: ["inner", "left", "right", "outer", "cross"]
	suffixes				# suffixes: Tuple[str]
)

# pd.concat
"""
Parameters
----------
"""
pd.concat(
	objs,					# objs: List[Series | DataFrame]
	axis = 0,				# axis: [0,1]
	join = "outer"			# join: ["inner", "outer"]
	keys = None				# keys: List[str]
	names = None			# names: List[str]
	ignore_index = False
)

# pd.combine
series.combine(
	other					# other: Series
)
data_frame.combine(
	other					# other: DataFrame
)
```
