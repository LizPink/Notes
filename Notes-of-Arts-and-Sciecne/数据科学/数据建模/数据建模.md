数据类
在Python中来自dataclass的`@dataclass`修饰器的功能可以帮助我们快速创建一个数据类，并且实现基本的`__init__`,`__repr__`,`__eq__`魔术方法。
```python
## Example1
from dataclasses import dataclass, field
@dataclass
class TrainingConfig:
    """
    Configuration for model training. Uses dataclasses tu auto-generate __init__, __repr__, __eq__ .
    """

    learning_rate: float = 0.001
    batch_size: int = 32
    epochs: int = 100
    optimizer: str = field(default = "adam")
    metrics: list[str] = field(default_factory=lambda : ["accruacy"])		# 防止多个实例公用同一个实例属性

    def __post_init__(self):
        if self.learning_rate <= 0:
            raise ValueError("learning_rate must be positive")
        if self.batch_size < 1:
            raise ValueError("batch_size must be at least 1")
        if self.epochs < 1:
            raise ValueError("epochs must be at least 1")
```
在例子1中这个类的等价形式相当于如下：
```python
class TrainingConfig:
    def __init__(self,learning_rate: float = 0.001, batch_size: int = 32, epochs: int = 100, optimizer: str = "adam", metrics: list[str] | None = None):
        self.learning_rate = learning_rate
        self.batch_size = batch_size
        self.epochs = epochs
        self.optimizer = optimizer
        self.metrics = ["accuracy"] if metrics is None else metrics
        self.__post_init__()

    def __post_init__(self):
        if self.learning_rate <= 0:
            raise ValueError("learning_rate must be positive")
        if self.batch_size < 1:
            raise ValueError("batch_size must be at least 1")
        if self.epochs < 1:
            raise ValueError("epochs must be at least 1")
```
