# 网格搜索选择
如果说交叉验证是在给定一组超参数的情况下计算模型的表现，网格搜索则进一步封装了超参数选择的过程。下面我们就来介绍一下网格搜索选择方法。首先我们需要构建好一个流水线Pipeline对象，用于后续的GridSearchCV寻找最优模型。

其次我们需要根据已经构建的Pipeline写好对应的模型参数，参数应当是一个字典或者字典列表。
```python
# sklearn.model_selection.GridSearchCV
## Grid Params (1)
param_grid =
{  
	"model__param1B": ["linear", "rbf"],  
	"model__param2B": [0.1, 1, 10],  
	"model__param3": [0.01, 0.1, 1]  
}  

## Grid Params (2)
param_grid = [  
	{  
		"model__param1A": ["linear"],  
		"model__param2A": [0.1, 1, 10]  
	},  
	{  
		"model__param1B": ["rbf"],  
		"model__param2B": [0.1, 1, 10],  
		"model__param3": [0.01, 0.1, 1]  
	}  
]
```
最后将构建好的。注意到GridSearchCV不仅可以调整模型本身的参数，还包括预处理阶段的学习器的参数，从工程化的角度讲，我们建议GridSearchCV不仅搜索模型的超参数，还搜索模型选择前的数据处理超参数，也就是说应该搜索整个数据流水线中涉及到的超参数。
```python
## Grid Object
"""
Parameters
----------
estimator: Pipeline
param_grid: Mapping
	用于指定训练模型对象的参数。
scoring: None | str | List[str]
	用于指定交叉验证中报告的模型评价指标。
refit: bool | str
	用于指定是否以及选择何种指标来根据最优参数再次训练模型。
"""
grid = model_selection.GridSearchCV(
	estimator,
	param_grid,
	scoring = None,
	refit = True,
	n_jobs = None
)


## Grid Output
grid.best_params_
grid.best_scores_		# 返回的是refit对应类型的指标分数
grid.best_estimator_

grid.cv_results_
```
