# 通用工具
## 管线类型
这一章我们介绍一些通用的数据分析工具。首先我们先介绍管线类型，管线类型是大规模进行数据分析任务的重要工具。管线类型是一类重要的Estimator学习器，它们可以连接其他的学习器。
### 类型定义
定义一个管线类型的基本语法如下。
```python
# sklearn.pipeline.Pipeline
pipe = pipeline.Pipeline(
	steps = [
		("step1_name", transformer),
		("step2_name", transformer),
		...,
		("setpn_name", estimator) 	# could be: transformer or predictor
	]
)
```

### 特征处理器类型
我们先介绍可以统一对不同类型的数据列做不同处理的工具，在sklearn中有ColumnTransformer列转换器类型专门提供这类接口。列转换器ColumnTransformer类型的主要用法是对不同的数据列采用不同的预处理方法，然后再把各个单独的处理结果拼接成最终处理结果。

| 函数或方法                                           | 功能  | 备注  |
| ----------------------------------------------- | --- | --- |
| compose.ColumnTransformer                       |     |     |
| compose.ColumnTransformer.get_feature_names_out |     |     |
```python
# Compose.ColumnTransformer
"""
Parameters
----------
transformers: List[int] | List[Tuples] | "passthrough"
remainder: ["drop", "passthrough"]
	用于指定未经处理的特征列的行为。默认参数"drop"表示丢弃；参数"passthrough"表示加入到最终的数据集中。
)
"""
preprocessor = skleran.compose.ColumnTransformer(
	transformers =
		[
			("step1_name", transformer, columns),
			...,
			("step2_name", transformer, columns)
		],
	remainder = "Drop" 
)
```
