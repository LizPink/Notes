## 模型评价
经典的线性模型是最基础机器学习模型，它的模型形式简单、训练速度块、可解释性强，适合作为特征和目标之间的线性关系基准拟合器，不过它也具有一些缺点：首先特征相对于样本数量过多的时候模型容易过拟合，过度依赖某一个特征，导致该特征系数过大。其次当特征列之间存在多重共线性问题时，预测系数可能不稳定，强线性相关之间的特征列具有系数融合趋势。
### 特征过拟合
当线性回归模型中特征数量相对于样本数量过大的时候，模型会出现过拟合的现象。模型会有充分的自由度拟合数据，这个时候模型的偏差可能会很小，但是代价是模型的方差很大，即学习到了噪声，导致泛化预测能力严重不足。
### 多重共线性
当特征列之间存在多重共线性问题的时候，强相关的特征列之间系数不唯一，并且系数波动范围很大。综合上述缺陷需要我们在经典线性回归模型的基础上引入一些约束条件，进而引出了后面带约束的线性模型。

接下来我们介绍Logistic分类模型的训练过程。其仍然属于监督学习模型，因此在训练的过程中必须带上标签。注意到在模型的训练过程中，该模型是默认带有正则项惩罚的，因此也可以作为一类正则线性回归。在模型输出的过程中，方法`predict`可以返回预测的对应类别，方法`predict_proba`会返回(n_samples, probability)的概率矩阵。方法`score`可以返回对应的accuracy准确率。
```python
# linear_model.LogisticRegression
model = linear_model.LogisticRegression(
	penalty = "l2"		# penalty: ["l1", "l2", "elasticnet", None]
	max_iter = 100
)

## Model Training
model.fit(X_train, y_train)

## Model Output
```
