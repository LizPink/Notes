集成学习的核心思想是通过集成多个弱的、不稳定的学习器，构成一个强的、稳定的学习器。我们之前在[[随机森林]]中学习到的随机森林模型便是一类集成了众多决策树模型的集成学习模型。集成学习模型可以广泛应用于分类、回归等任务中。本章我们会频繁接触`sklearn.ensemble`模块的众多接口。

# 模型设定
集成学习模型中，主要的集成原则主要包括以下几类，彼此之间可以相互组合并不互斥。

| 集成原则     | 含义                | 模型之间的关系 |
| -------- | ----------------- | ------- |
| Voting   | 多个模型投票/平均决策       | 并列      |
| Bagging  | 多个在样本的随机子集上训练随机特征 |         |
| Boosting | 后一个模型重点修正前一个模型的误差 | 顺序      |
| Stacking | 用新的模型学习如何组合现有模型   | 分层      |
