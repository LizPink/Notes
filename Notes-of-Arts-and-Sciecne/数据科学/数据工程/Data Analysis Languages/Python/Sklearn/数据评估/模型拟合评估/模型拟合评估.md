本部分我们来介绍如何可视化模型的学习过程，以及如何根据学习过程评价模型的拟合表现以及后续改进方向。为了可视化学习过程我们会绘制模型的学习曲线和验证曲线。学习曲线是用来描述模型随着学习样本数量与训练表现和验证表现的关系的图像，可以分析模型是否存在欠拟合/过拟合现象；验证曲线是用来描述模型的一个参数变化与模型训练表现和验证表现的关系的图像，可以用来分析模型相对于某一个参数的敏感程度。
# 学习曲线
学习曲线的具体工作原理是，根据交叉验证参数划分训练集和验证集，随后每次交叉验证中都根据`train_sizes`中接受的参数列表，抽取训练集中对应比例的样本真正参与模型训练，最后对每个训练比例汇总其在每次交叉验证中的平均训练分数和验证分数。
```python
# sklearn.model_selection.learning_curve
train_sizes, train_scores, val_scores = model_selection.learning_curve(
	estimator,
	X,
	y,
	train_sizes,
	cv,
	scoring,
	n_jobs = None
)
```
