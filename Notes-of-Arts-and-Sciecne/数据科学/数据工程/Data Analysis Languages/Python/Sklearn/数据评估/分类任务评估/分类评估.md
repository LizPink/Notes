# 通用评价指标
分类任务的评价指标主要包括如下几种：准确率、查准率、查全率、平均率。下面我们逐一进行介绍。
## 准确率
### 指标概念
准确率$\rm{Accuracy}$的定义如下，衡量的是模型预测正确样本占总样本数的比率。
$$
	\rm{Accuracy}:=\frac{y_{true}.count()}{y_{pred}.count()}
$$
### 指标计算
```python
# sklearn.metric.accuracy_score
acc = metrics.accuracy_score(
	y_true,
	y_pred
)
```
### 指标评价
准确率高就好并不是越高越好，需要考虑各个类别的在样本中的占比。

## 查准率
查准率$\rm{Precision}$是衡量模型预测某一类别的正确能力，其定义如下。
$$
	\rm{precision}_{C}:=\frac{真实为C的样本数}{预测为C的样本数}
$$

## 查全率
查全率$\rm{Recall}$衡量的是模型预测某一类别的完全能力，其定义如下。
$$
	\rm{recall}_C:=\frac{预测为C的样本数}{真实为C的样本数}
$$
```python
# sklearn.metrics
"""
Parameters
----------
average: ["binary", "samples", "micro", "macro", "weighted"] | None
	用于指定多分类的加权平均方式。其中macro表示算术平均，而weighted表示按照类别数量加权表示。
"""
recall = metrics.recall(
	y_true,
	y_pred,
	average = "binary"		# average: ["binary", "samples", "micro", "macro", "weighted"] | None
)
```
## 平均率
通常来说某一类别的查准率和查全率存在此消彼长的取舍关系，而F1-Score综合反映了两者的水平。指标F1-Score定义为查准率和查全率的调和平均数（对较小值更加敏感）。
```python
f1_score = metrics.f1_score(
	y_true,
	y_pred,
	average = "binary"
)
```
### 指标评价
可以通过调用`metrics.classification_report()`接口得到分类任务中的准确率、查准率、查全率、平均率等相关数据。

## 混淆矩阵
### 指标概念
混淆矩阵涵盖了准确率、查准率、查全率等多个分类指标，进一步衡量了模型的分类能力。混淆矩阵的表示形式为

|          | y_pred_1 | y_pred_2 | ... | y_pred_n |
| -------- | -------- | -------- | --- | -------- |
| y_true_1 |          |          |     |          |
| y_true_2 |          |          |     |          |
| ...      |          |          |     |          |
| y_true_n |          |          |     |          |
### 指标计算
要根据一个模型的预测结果计算混淆矩阵，可以直接调用如下接口。
```python
# sklearn.metrics.confusion_matrix
"""
parameters
----------
labels: 用于指定参与矩阵计算的标签以及标签的顺序。
"""
confusion_matrix = metrics.confusion_matrix(
	y_true,
	y_pred,
	labels = ...,
	normalize = None	# normalize: ["true", "pred", "all"]
)
```
混淆矩阵还支持可视化展示，需调用`metrics.ConfusionMatrixDisplay`的相关接口。
```python
# sklearn.metrics.ConfusionMatrixDisplay
metrics.ConfusionMatrixDisplay.from_predictions(
	y_true,
	y_pred,
	labels = ...,
	normalize = None	# normalize: ["true", "pred", "all"]
)
```

# 概率模型指标
对于概率分类模型或者分数分类模型（比如支持向量机），除了上述通用的分类评价指标之外，我们还关心模型的概率分类阈值对分类效果的影响，并且提出了若干相关的评价指标。
## ROC Curve
曲线ROC旨在衡量不同的分类阈值下，二分类模型TPR (True Positive Rate = Recall) 和FPR (False Positive Rate) 的关系，即衡量模型完全预测正类别的能力，其中TPR是纵轴而FPR是横轴。
```python
metrics.RocCurveDiaplay.from_estimator(
	estimator,
	X,
	y,
	pos_label = None
)
```
### 指标评价
分数ROC-AUC高，说明模型整体能够把正类排在负类前面，但是并不一定说明模型本身学习到了良好的分类能力，尤其是在样本分类不均衡的时候。
