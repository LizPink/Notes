# 数据划分
在机器学习模型中，数据集一般会被划分为训练集、测试集、验证集。其中训练集用于训练给定模型，以寻找模型的最优参数。而测试集是为了验证模型的样本外表现能力，以衡量模型的泛化能力。这一章我们会频繁用到`sklearn.model_selection`库的相关接口。

| 函数或方法                                                                      | 功能  | 备注  |
| -------------------------------------------------------------------------- | --- | --- |
| model_selection.train_test_split <br>-> [x_train, x_test, y_train, y_test] |     |     |
```python
# Dataset Segregation
"""
Parameters
----------
shuffle: bool
	用于控制是否在划分前打乱数据。对于截面数据可以选择shuffle，而对于时间序列数据则需要进行更合理的shuffle.
stratify: bool
	用于控制是否需要分层抽样。依赖于shuffle=True打乱数据。对于不平衡的分类任务数据可以选择对y进行分层抽样。
"""
X_train, X_test, y_train, y_test = sklearn.nodel_selection.train_test_split(
	*arrays,			# arrays: ArrayLike
	train_size,
	test_size,
	random_state,
	shuffle = True,
	stratify = None
)
```
## 数据集划分策略
一般来说数据集需要划分为三个部分：训练集、验证集、测试集。验证集用于选择模型的超参数，训练集用于训练选型超参数的模型，验证集用于检验模型的样本外表现。在实践中数据集的划分策略有很多种，这里我们介绍比较经典的划分方法。
### 固定验证划分
针对于截面数据，最基本的策略是按照一个固定的比例划分数据集、验证集、测试集。
```python
X_train, X_test, y_train, y_test = model_selection.train_test_split(
	X,y,
	test_size,
	random_state,
	shuffle = True,
	stratify
)

X_train, X_val， y_train, y_val = model_selection.train_test_split(
	X_train, y_train,
	test_size,
	random_state,
	shuffle = True,
	stratify
)
```
### 交叉验证划分
如前所述我们介绍了固定比例随即划分数据集的过程，该方法的缺点是数据利用率不高，同时验证集划分、超参数选择的偶然性较高。现在我们介绍截面数据的另一种更精细的划分方法——交叉验证划分法。交叉验证法只在模型选择的时候区分训练集和验证集，当模型确定之后训练集和验证集将合并为训练集用于模型训练；此外在模型选择时，选择一个折数K将训练集和验证集整体平分为K等份，将其中的K-1份用于训练超参数，另外1份用于验证超参数。这就是交叉验证法的思想，亦称为K折交叉验证法。由于交叉验证方法经常和模型选择绑定到一起，我们会在[[模型选择]]部分具体介绍具体的代码实现。

### 时间序列划分
前面我们讨论的划分方法适用于截面数据。而相对于截面数据，时间序列数据的划分一定要遵循顺序，因为用未来的数据进行训练并预测的过去发生的事情是不合逻辑的，因此时间序列数据有专门的方法。


# 数据缩放
这一节我们介绍数据缩放的相关知识，在实际建模的过程中，不同特征由于量纲不同，其数据大小也有所不同，这会影响到模型的学习效果。比如数据量纲小的数值就很大，对于一些指标（比如距离）等影响作用就大，然而我们不想单纯因为数据表示量纲而不是数据本身反应的性质就导致模型选择的偏向，因此机器学习过程中会广泛应用到数据缩放的技术，下面我们就一一进行介绍。

| 函数或方法                                 | 功能            | 备注  |
| ------------------------------------- | ------------- | --- |
| sklearn.prepossessing.StandardScalaer | 使用平均数和标准差进行缩放 |     |
| sklearn.prepossessing.MinMaxScaler    | 使用最大数和最小数进行缩放 |     |
| sklearn.prepossessing.RobustScaler    | 使用中位数和分位距进行缩放 |     |
```python
# Scaling Data
scaler = sklearn.prepossessing.StandardScaler()

scaler.fit(X_train)
X_scaled = scaler.transform(X_train)

## Equivalent
X_scaler.fit_transform(X_train)
```

# 数据编码
这一节我们介绍文本编码的相关知识，在实际的建模过程中，我们不止会受到数值型数据，还会受到文本型数据。文本型数据如果可以经过适当的数值化处理，也可以作为分析的对象。特别地对于具有类别属性的文本数据，有一些比较成熟的编码分析方案，这里我们就来介绍类别类型文本的编码方法。

| 函数或方法                                | 功能          | 备注  |
| ------------------------------------ | ----------- | --- |
| sklearn.prepossessing.OneHotEncoder  |             |     |
| sklearn.prepossessing.OrdinalEncoder |             |     |
| sklearn.prepossessing.LabelEncoder   | 用于对标签文本进行编码 |     |
进行编码操作的具体接口如下，注意到编码之后的数据格式符合数据矩阵的约定。
```python
# OneHotEncoding
"""
Input
-----
X: List | NDArray
handle_unknown: ["error", "ignore"]
	用于处理面对未知类型的编码方式。ignore会为所有的未知类型统一编码为0.
"""
encoder = sklearn.preprocessing.OneHotEncoder(
	sparse_output = True,
	handle_unknown = "error"	# handle_unknown: ["error", "ignore"]
)
X_encoded = encoder.fit_transform(X)
```
```python
# OrdinalEncoding
"""
Input
-----
X: List | NDArray
"""
encoder = sklearn.preprocessing.OrdinalEncoder(
	categories,					# categories: List[ArrayLike]
	handle_unknown = "error"
)
X_encoded = encoder.fit_transform(X)
```
