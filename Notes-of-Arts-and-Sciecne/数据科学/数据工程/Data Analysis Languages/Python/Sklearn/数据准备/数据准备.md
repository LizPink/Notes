在Sklearn中，所有的机器学习模块都遵循统一一个风格的逻辑抽象：数据和==Estimator==学习器。其中数据可以分为特征数据和标签数据，特征数据一般是以特征矩阵的方式进行存储，一行代表一个样本，一列代表一个特征维度，而标签数据一般是以标签向量或标签矩阵的方式进行存储的，一个行代表一个样本标签，一个列代表标签的一个维度。学习器可以分为Transformer转换器和Predictor预测器。同时有四个重要的方法：fit方法、transform方法、predict方法、score方法。我们会在余下的章节中陆续介绍这些内容，现在我们先来介绍数据准备方面的内容。

## 数值特征缩放
这一节我们介绍数据缩放的相关知识，在实际建模的过程中，不同特征由于量纲不同，其数据大小也有所不同，这会影响到模型的学习效果。比如数据量纲小的数值就很大，对于一些指标（比如距离）等影响作用就大，然而我们不想单纯因为数据表示量纲而不是数据本身反应的性质就导致模型选择的偏向，因此机器学习过程中会广泛应用到数据缩放的技术，下面我们就一一进行介绍。

| 函数或方法                                 | 功能            | 备注  |
| ------------------------------------- | ------------- | --- |
| sklearn.prepossessing.StandardScalaer | 使用平均数和标准差进行缩放 |     |
| sklearn.prepossessing.MinMaxScaler    | 使用最大数和最小数进行缩放 |     |
| sklearn.prepossessing.RobustScaler    | 使用中位数和分位距进行缩放 |     |
```python
# Scaling Data
```

# 特征处理
这一章我们介绍如何通过已有的数据构建更多的特征，以及从已经构建的特征中筛选出有用的特征。
## 特征构造
特征构造可以帮助我们从已有的特征中生成更多的交互特征，增强模型的表达能力。在特征构造中我们经常使用PolynomialFeatures接口构造多项式交互特征。

| 函数                               | 功能  | 备注  |
| -------------------------------- | --- | --- |
| preprocessing.PolynomialFeatures |     |     |
```python
# preprocessing.PolynomialFeatures
"""
Parameters
----------
include_bias: bool
	用于决定是否在结果中引入常数项。
"""
poly = preprocessing.PolynomialFeatures(
	degree = 2,				# degree: int
	include_bias = False
)
X_poly = poly.fit_transform(X)
```
在使用时需要特别注意，多项式特征构造下生成的特征个数会以$O(n^{degree})$迅速增多，所以在特征构造时要注意相关的开销问题。

## 特征选择
当我们构建了充分多的特征之后，剩下的问题自然是哪些特征比较重要，哪些特征不重要。删除不重要的特征便是这一节特征选择中我们需要了解的内容，本节我们会频繁接触sklearn.feature_selection模块。

| 函数                                  | 功能          | 备注  |
| ----------------------------------- | ----------- | --- |
| feature_selection.VarianceThreshold | 根据方差筛选特征列   |     |
| feature_selection.SelectKBest       | 根据评分函数筛选特征列 |     |
```python
# feature_selection.Variance_Threshold
selector = feature_selection.Variance_Threshold(
	threshold = 0,		# threshold: float
)
X_selected = selector.fit_transform(X)
```
对于SelectKBest方法，其评分函数的选择有如下种类。在分类任务中，f_classif主要是计算方差分析中的f统计值，意图在于分析每类特征在不同的标签组中均值的变化情况，如果一个特征在不同组之间相差明显，而组内差异较小，那么这个标签就更有区分度，其ANOVA F-value分数就越高。chi2主要是计算每个特征与每个标签组之间的卡方统计量，用来统计该特征出现的频率是否独立与一个标签组。

| 评分函数                   | 评分依据             | 评分指标               | 适用情况                  |
| ---------------------- | ---------------- | ------------------ | --------------------- |
| *分类任务*                 |                  |                    |                       |
| f_classif              | 特征在不同标签组中的均值变化程度 | ANOVA F-value      | 连续特征、不同类别的差异主要体现为均值差异 |
| chi2                   | 特征在不同标签组中出现的频率   | chi2               | 离散特征、                 |
| mutual_info_classif    | 特征与标签之间的信息依赖程度   |                    |                       |
| *回归任务*                 |                  |                    |                       |
| f_regression           | 特征与标签之间的线性关系强弱   | Linear P-Value     |                       |
| r_regression           | 特征与标签之间的相关程度     | Linear coefficient |                       |
| mutual_info_regression | 特征与标签之间的信息依赖程度   | Mutual Information |                       |
```python
# feature_selection.SelectKBest
"""
Parameters
----------
score_func: func
	用于指定评分函数。其中用于分类任务的评分函数有f_classif, chi2, mutual_info_classif，用于回归任务的评分函数有f_regression, r_regression, mutual_info_regression。
"""
selecor = feature_selection.SelectKBest(
	score_func = f_classif,		# score_func: func
	k = 10
)
X_selected = selector.fit_transform(X, y)
```
