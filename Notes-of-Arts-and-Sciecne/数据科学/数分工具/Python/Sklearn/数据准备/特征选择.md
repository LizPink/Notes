# 特征处理
这一章我们介绍如何通过已有的数据构建更多的特征，以及从已经构建的特征中筛选出有用的特征。
## 特征构造
特征构造可以帮助我们从已有的特征中生成更多的交互特征，增强模型的表达能力。在特征构造中我们经常使用PolynomialFeatures接口构造多项式交互特征。

| 函数                               | 功能  | 备注  |
| -------------------------------- | --- | --- |
| preprocessing.PolynomialFeatures |     |     |
```python
# preprocessing.PolynomialFeatures
"""
Parameters
----------
include_bias: bool
	用于决定是否在结果中引入常数项。
"""
poly = preprocessing.PolynomialFeatures(
	degree = 2,				# degree: int
	include_bias = False
)
X_poly = poly.fit_transform(X)
```
在使用时需要特别注意，多项式特征构造下生成的特征个数会以$O(n^{degree})$迅速增多，所以在特征构造时要注意相关的开销问题。

## 特征选择
当我们构建了充分多的特征之后，剩下的问题自然是哪些特征比较重要，哪些特征不重要。删除不重要的特征便是这一节特征选择中我们需要了解的内容，本节我们会频繁接触sklearn.feature_selection模块。

| 函数                                  | 功能          | 备注                     |
| ----------------------------------- | ----------- | ---------------------- |
| feature_selection.VarianceThreshold | 根据方差筛选特征列   |                        |
| feature_selection.SelectKBest       | 根据评分函数筛选特征列 |                        |
| feature_selection.SelectFromModel   | 根据训练模型的结果筛选 | 单次迭代                   |
| feature_selection.RFE               |             | 多次迭代；需要模型能够提供特征权重或者重要性 |
```python
# feature_selection.Variance_Threshold
selector = feature_selection.Variance_Threshold(
	threshold = 0,		# threshold: float
)
X_selected = selector.fit_transform(X)
```
### 评分选择
对于SelectKBest方法，其评分函数的选择有如下种类。在分类任务中，f_classif主要是计算方差分析中的f统计值，意图在于分析每类特征在不同的标签组中均值的变化情况，如果一个特征在不同组之间相差明显，而组内差异较小，那么这个标签就更有区分度，其ANOVA F-value分数就越高。chi2主要是计算每个特征与每个标签组之间的卡方统计量，用来统计该特征出现的频率是否独立与一个标签组。

| 评分函数                   | 评分依据           | 评分指标               | 适用情况      |
| ---------------------- | -------------- | ------------------ | --------- |
| *分类任务*                 |                |                    |           |
| f_classif              | 特征在不同标签组中的均值差异 | ANOVA F-value      | 连续特征      |
| chi2                   | 特征在不同标签组中出现的频率 | $\chi^2$ Statistic | 离散计数特征    |
| mutual_info_classif    | 特征与标签之间的信息依赖程度 |                    | 存在非线性依赖关系 |
| *回归任务*                 |                |                    |           |
| f_regression           | 特征与标签之间的线性相关程度 | Linear P-Value     |           |
| r_regression           | 特征与标签之间的线性相关程度 | Linear coefficient |           |
| mutual_info_regression | 特征与标签之间的信息依赖程度 | Mutual Information | 存在非线性依赖关系 |
```python
# feature_selection.SelectKBest
"""
Parameters
----------
score_func: func
	用于指定评分函数。其中用于分类任务的评分函数有f_classif, chi2, mutual_info_classif，用于回归任务的评分函数有f_regression, r_regression, mutual_info_regression。
"""
selecor = feature_selection.SelectKBest(
	score_func = f_classif,		# score_func: func
	k = 10
)

```
### 训练选择
模型训练选择 (SelectFromModel) 选择特征的思路是：用数据训练一边模型，根据模型的特征重要性和给定阈值，筛选出满足阈值条件的特征。迭代训练选择 (Recursive Feature Selection, RFE) 选择重要特征的思路是：先用全部特征训练一个模型；根据模型给出的特征重要性，删掉最不重要的一部分；随后再用剩下的特征重新训练；最后一直重复上述步骤，直到剩下指定数量的特征。关于如何获得特征重要性，SelectFromModel和RFE算法主要是根据估计器的`coef_`或者`feature_importance_`来筛选特征。
```python
# feature_selection.SelectFromModel
"""
Parameters
----------
threshold: str
	用于筛选特征。可以选择"mean"，也可以选择诸如"1.5*mean"这种计算式。
"""
X,y = datasets.load_iris(return_X_y=True)

estimator = ensemble.RandomForestClassifier(random_state=42)
selector = feature_selection.SelectFromModel(
    estimator = estimator,
    threshold = "mean"			# threshold: str
)
X_new = selector.fit_transform(X,y)
print( X.shape, X_new.shape )
```
```python
# feature_selection.RFE
selector = feature_selection.RFE(
	estimator,
	n_features_to_select
)
X_new = selector.fit_transform(X, y)
print( selector.support_, selector.ranking_, sep = "\n-----\n" )
```
