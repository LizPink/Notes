# 正则线性回归
在前述[[数据科学/数分工具/Python/Sklearn/数据建模/线性模型/线性模型]]讨论的基础上我们介绍了基础的线性模型，其存在一些不足，因此数据科学家提出了改进后的线性回归模型，通过增加回归系数的惩罚项来改进模型的缺陷。
## 模型设定
正则线性LASSO回归、Ridge回归分别采用L1正则和L2正侧约束项加入到模型的损失函数中，起到限制系数大小与特征选择或稳定系数估计的作用。正则线性ElasticNet回归则是综合了前两者的约束项作为自己的损失函数，兼顾LASSO和Ridg模型的性质。
## 模型训练
下面我们介绍模型训练的过程。由于正则线性模型均对回归系数做了约束，因此回归系数的大小对于减小损失函数就显得非常重要，也因此要注意数据的缩放问题，因为不缩放的特征会导致特征仅仅因为单位变化导致的系数变化就受到不同的筛选行为，而不是因为特征与目标本身内涵的互动关系。
```python
# linear_model.Lasso
model = linear_model.Lasso(
	alpha = 1
)
```
```python
# linear_model.Ridge
model = linear_model.Ridge(
	alpha = 1
)
```
```python
# linear_model.ElasticNet
model = linear_model.ElasticNet(
	alpha = 1
	l1_ratio = 0.5
)
```
