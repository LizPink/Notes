在进行因果实验的时候，根据数据的业务地位可以分为：主指标（主要研究的指标）、辅助指标（研究主指标的机制解释）、护栏指标（业务最重要的指标）；根据数据的统计检验方法可以分为转化指标、均值指标、比率指标。



常见错误赏析
这样写的`WHERE`极有可能过滤掉左表t1中存在但是右表数据为空的记录，实际效果类似于一个内连接。
```SQL
SELECT
FROM
	table1 AS t1
	LEFT JOIN table2 AS t2
WHERE
	...
```
应当谨慎对待连续左连接，尤其是将(1)汇总表与明细表或者(2)明细表与明细表连接到一起，因为这样极有可能引起数据行膨胀，导致数据被重复计算。

# 经营数据
## 留存率
### 留存率
如果说用户的不同周期的活跃数是存在于同一列里的，我们就需要分组聚合多行，将行数据转换为列标签，再根据列标签进行统计。例如考虑下面这一个问题，
```
TABLE: user_activity
+---------+--------------+--------------+
| user_id | period_label | activity_cnt |
+---------+--------------+--------------+
| 1       | pre_7d       | 2            |
| 1       | activity     | 1            |
| 1       | post_7d      | 3            |
| 2       | pre_7d       | 1            |
| 2       | activity     | 1            |
| 2       | post_7d      | 0            |
| 3       | pre_7d       | 1            |
| 3       | activity     | 0            |
| 3       | post_7d      | 0            |
| 4       | pre_7d       | 0            |
| 4       | activity     | 2            |
| 4       | post_7d      | 1            |
| 5       | pre_7d       | 0            |
| 5       | activity     | 1            |
| 5       | post_7d      | 0            |
+---------+--------------+--------------+
```
对应的要计算列标签的方法为：
```SQL
SELECT
	user_id,
	MAX(
		CASE period_label
			WHEN 'pre_7d' THEN 1
			ELSE 0
		END
	) AS pre_7d_active_label,
	MAX(
		CASE period_label
			WHEN 'activity' THEN 1
			ELSE 0
		END
	) AS activity_active_label,
	MAX(
		CASE period_label
			WHEN 'post_7d' THEN 1
			ELSE 0
		END
	) AS post_7d_active_label
FROM
	user_activity
GROUP BY
	user_id,
	period_label
```
