# 种子程序
种子程序 (Boot Loader) 是开机启动是最先执行的程序，负责引导机器启动，包括根据规定好的的内存分区将操作系统加载到内存区域中。下面是一个最小的种子程序代码。在这段代码中，种子程序首先从外部存储读取64个字节的操作系统，并且写入到对应的内存分区中，随后引导中央处理器找到并执行操作系统程序的指令。
```assembly
0x00 11 40		# 设置 C=64
0x02 12 40		# 设置 P=0x40

0x04 30			# 检查输入并设置 A
0x05 52 FD		# 如果 A=0 则 PC=0x04

0x07 31			# 读取输入并设置 A
0x08 23			# 将 A 写入内存并设置 P=P+1
0x09 43			# 设置 C=C-1
0x0A 55 F8		# 如果 C!=0 则 PC=0x04
0x0C 50 40		# 设置 PC=0x40
0x0E 00 00
```

## 内核系统
操作系统是第一个引导执行的程序，一般会预先烧录到一个物理介质中等待种子程序的加载。操作系统最核心的功能包括，这些功能称为 Kernel 内核。
### 常驻监控程序
这里我们设计的最小操作系统只负责实现最基本的功能：加载并运行用户输入的程序。操作系统首先会通过LOAD分支读取用户程序的长度和加载地址，然后按照地址写入到内存的程序区，随后可以通过RUN分支执行该程序。
```assembly
操作系统区: 0x40-0x7F
--------------------
0x40 30			# 检测输入
0x41 52 FD		# 如果 A=0 跳转至0x40
0x43 31			# 否则读取输入
0x44 52 05		# 如果 A=0 跳转 0x48 LOAD分支

# RUN分支
0x46 30			# 检测输入 A
0x47 52 FD		# 如果 A=0 跳转 0x46
0x49 31			# 否则读取输入
0x4A 51			# PC = A

# LOAD 分支
## 读取要存储的程序地址
0x4B: 30 		# 检测输入状态  
0x4C: 52 FD 	# 如果 A = 0，跳转 0x4B  
0x4E: 31 		# 读取装载地址到 A  
0x4F: 14 		# P = A  
  
## 读取要存储的程序大小
0x50: 30 		# 检测输入状态  
0x51: 52 FD 	# 如果 A = 0 跳转 0x50  
0x53: 31 		# 读取装载长度到 A  
0x54: 13 		# C = A  
0x55: 54 08 	# 如果 C = 0 跳转 0x5F 返回 monitor_loop  
  
## 读取程序写入对应地址 
0x57: 30 		# 检测输入状态  
0x58: 52 FD 	# 如果 A = 0 跳转 0x57  
0x5A: 31 		# 读取输入 1 字节数据到 A  
0x5B: 23 		# MEM[P] = A; P = P + 1  
0x5C: 43 		# C = C - 1  
0x5D: 55 F8 	# 如果 C != 0 跳转 0x57  
  
0x5F: 50 40 	# 跳回 monitor_loop
```
