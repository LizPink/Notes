# 种子程序
种子程序 (Boot Loader) 是开机启动是最先执行的程序，负责引导机器启动，包括根据规定好的的内存分区将操作系统加载到内存区域中。下面是一个最小的种子程序代码。在这段代码中，种子程序首先从外部存储读取64个字节的操作系统，并且写入到对应的内存分区中，随后引导中央处理器找到并执行操作系统程序的指令。
```assembly
0x00 11 40		# 设置 C=64
0x02 12 40		# 设置 P=0x40

0x04 30			# 检查输入并设置 A
0x05 52 FD		# 如果 A=0 则 PC=0x04

0x07 31			# 读取输入并设置 A
0x08 23			# 将 A 写入内存并设置 P=P+1
0x09 43			# 设置 C=C-1
0x0A 55 F8		# 如果 C!=0 则 PC=0x04
0x0C 50 40		# 设置 PC=0x40
0x0E 00 00
```

### 常驻监控程序
这里我们设计的最小操作系统只负责实现最基本的功能：写入内存、读取内存、运行用户程序。操作系统支持LOAD、RUN、DUMP等三个命令。其中LOAD命令写入内存指定地址和长度的内容，然后按照地址写入到内存的程序区。RUN命令执行给定地址的程序；DUMP命令读取内存中指定地址和长度的内容。

### 编码转换程序
这一次我们实现一个机器码显示程序，这个程序允许我们将硬件层的二进制机器码转换为应用层的ASCII码格式，这将方便我们通过ASCII码与机器进行交流。具体而言该程序分为一个输入程序和一个输出程序。输出程序读取内存的一个二进制字节，将其视为十六进制的格式并输出这两个十六进制字符的ASCII码，最后返回操作系统。

> [!example] Example
> 内存地址: 0b01001111B = 0x4F <-> 0x34('4') + 0x46('F')

```seudo_code
---------
A = A - 0x0A

原半字节在 0-9  
A = A + 0x3A 

否则：  
原半字节在 10-15  
A = A + 0x41
```
