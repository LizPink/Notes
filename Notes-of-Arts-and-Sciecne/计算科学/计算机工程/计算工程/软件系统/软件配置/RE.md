正则表达式是一种通用的文本匹配规则。
# 正则表达规则
正则匹配引擎的基本算法是：从左到右，先找最早能成功的位置，如果整个表达式失败，就往后移动起点。在此基础上贪婪算法是先尽可能多匹配，失败了再回溯；非贪婪算法是先尽可能少匹配，失败了再扩展。

| 字符串          | 规则          | 注释                   |
| ------------ | ----------- | -------------------- |
| ***通配符***    | <           | <                    |
| .            | 匹配除了\n之外的字符 |                      |
| ***字符集***    | <           | <                    |
| [1234]       |             |                      |
| [abcd]       |             |                      |
| [0-9]        |             |                      |
| [a-z]        |             |                      |
| [A-Z]        |             |                      |
| [0-9a-z]     |             |                      |
| [0-9a-zABCD] |             |                      |
| ***边界信息***   | <           | <                    |
| '^'          | 匹配字符串开头     |                      |
| '$'          | 匹配字符串结尾     |                      |
| '\A'         | 匹配字符串的文本开头  |                      |
| '\Z'         | 匹配字符串的文本结尾  |                      |
| '\b'         | 匹配边界单词      | 边界单词本身是为'\w'而右边为'\W' |
| '\B'         | 匹配非边界单词     |                      |

| 字符串       | 规则      | 注释        |
| --------- | ------- | --------- |
| ***转义符*** | <       |           |
| r'\d'     | 匹配数字    | 0-9       |
| r'\D'     | 匹配非数字   |           |
| r'\w'     | 匹配单词字符  | a-zA-Z0-9 |
| r'\W'     | 匹配非单词字符 |           |
| r'\s'     | 匹配空白字符  |           |
| r'\S'     | 匹配非空白字符 |           |

| 字符串                    | 规则      | 注释                |
| ---------------------- | ------- | ----------------- |
| ***量词***               | <       | <                 |
| '*'                    | 0次或任意多次 |                   |
| '+'                    | 1次或任意多次 |                   |
| '?'                    | 0次或者1次  |                   |
| '{m}'                  | m次      |                   |
| '{m,n}'                | n-m次    |                   |
| '*?','+?','{m,n}?'     | 非贪婪匹配   | 以尽量少的字符完成匹配       |
| ***分组***               | <       | <                 |
| '\|'                   |         |                   |
| '()'                   |         |                   |
| '(?P<分组名>)','(?P=分组名)' |         |                   |
| ***常用规则***             | <       | <                 |
| re.I                   |         |                   |
| re.M                   | 多行匹配    | 修改'^'的语法含义为“每行行首” |
| re.I \| re.M           |         |                   |
