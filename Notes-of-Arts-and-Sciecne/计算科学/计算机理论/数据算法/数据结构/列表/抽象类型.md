向量和列表是两类重要的线性数据结构或者序列（Sequence）结构。
# 抽象数据类型
一般来说向量类型应该具有这些接口。

```cpp
#pragma once
#include <iostream>

template <typename T>
class Array
{
public:
	// 构造函数
	Array(int size = 10);
	// 析构函数
	~Array();

public:
	// 增加元素：末尾
	void insert_back(T val);
	// 删除元素：末尾
	void erase_back();
	// 增加元素：任意位置
	void insert(int pos, T val);
	// 删除元素：任意位置
	void erase(int pos);
	// 查询元素：任意值
	int find(T val);

	void show() const;

private:
	void expand(int size);	// 数组扩容

private:
	T* mptrArr;		// 指向可扩容的数组内存
	int mCapacity;	// 数组的容量
	int mElement;	// 数组的元素个数（可以当作哨兵下标）
};
```

# 类型评价
数组结构的优点为：
- 元素访问：任意位置访问的时间复杂度为$\Theta(1)$.
- 元素增删：末尾位置的元素增删时间复杂度为$\Theta(1)$.

数组结构的缺点为：
- 元素增删：中间位置的元素增删时间复杂度为$O(n)$.
- 数组扩容：扩容的时间复杂度为$\Theta(n)$.
