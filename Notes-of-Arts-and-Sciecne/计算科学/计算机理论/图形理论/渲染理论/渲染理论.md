## 光线追踪架构
光线追踪的基本架构如下：
```cpp
struct viewPort(W,H);
Color viewBuffer[W][H];

for (int x=0; x<W; x++)
{
	for (int y=0; y<H; y++)
	{
		Color clolor = renderPixel(x,y);
		viewBuffer = color;
	}
}
```

光线追踪的基本计算图如下：
$$
	p_\text{world} \overset{V}{\longrightarrow} p_\text{view} \overset{C}{\longrightarrow} p_\text{clip} \overset{\div w}{\longrightarrow}p_\text{ndc}\overset{S}{\longrightarrow}p_\text{screen}
$$

## 光栅架构
光栅架构的基本架构如下：
```cpp
Color viewPort[W][H];

for (shape in Shapes)
{
	// 计算当前shape占据了哪些像素
	Point pixel_coords[] = Rasterize(shape, &pixel_coords);
	// 将这些像素值写入屏幕中
	for (Point p in pixel_coords)
	{
		viewPort[p.x][p.y] = color;
	}
}
```
