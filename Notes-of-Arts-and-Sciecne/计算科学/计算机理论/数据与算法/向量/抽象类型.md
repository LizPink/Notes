向量和列表是两类重要的线性数据结构或者序列（Sequence）结构。
# 抽象数据类型
一般来说向量类型应该具有这些接口。

| 操作                | 功能                     | 适用对象 |
| ----------------- | ---------------------- | ---- |
| ***构造与析构***       | <                      | <    |
| ***属性访问***        | <                      | <    |
| `size()`          | 访问向量当前的元素个数            | 向量   |
| `get(r)`          | 访问`r`位置                | 向量   |
| `traverse(func)`  | 遍历向量并处理所有元素            | 向量   |
| ***增删改查***        | <                      | <    |
| `insert(r, e)`    | 在`r`位置插入`e`元素          | 向量   |
| `remove(r)`       | 删除`r`位置的元素             | 向量   |
| `remove(lo,hi)`   | 删除`[lo,hi)`位置的元素       | 向量   |
| `replace(r,e)`    | 在`r`位置写入`e`元素          | 向量   |
| `search(e,lo,hi)` | 在区间`[lo,hi)`查找`e`元素的位置 | 向量   |
| ***去重***          | <                      | <    |
| `unique()`        | 剔除重复元素                 | 向量   |
| `unique()`        | 剔除重复元素                 | 有序向量 |
| ***排序***          | <                      | <    |
| `disordered()`    | 判断所有元素是否已按顺序排列         | 有序向量 |
| `sort()`          | 调整各元素的位置，使之按非降序排列      | 有序向量 |
