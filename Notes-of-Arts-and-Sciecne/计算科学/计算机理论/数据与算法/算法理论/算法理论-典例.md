# 算法概念
举一个经典例子，如果将序列HailStone视为一组指令序列，那么这个指令序列目前还不能称之为一个算法，因为其有穷性还未得到正式证明。
> [!example] HailStone
> 定义序列Hailstone(n)为
> $$
> 	\rm{HailStone}:=
> 	\begin{cases}
> 		1& ,n=1 \\
> 		\{n\} \cup \rm{HailStone}(n/2) &,n \text{ is even} \\
> 		\{n\} \cup \rm{Hailstone}(3n+1) &,n \text{ is odd}
> 	\end{cases}
> $$

### 循环逻辑分析
循环逻辑的复杂度分析经常等效于计算一个级数的阶数。常见级数的渐进估计的结论如下。

| 级数                                  | 渐进复杂度      | 备注  |
| ----------------------------------- | ---------- | --- |
| *算术级数*                              | <          | <   |
| $$S:=\sum_{k=0}^{+\infty}k$$        | $$O(k^2)$$ |     |
| *几何级数*                              | <          | <   |
|                                     |            |     |
| *调和级数*                              |            |     |
|                                     |            |     |
| *对数级数*                              |            |     |
| $$S:=\sum_{k=0}^{+\infty}{\log k}$$ |            |     |
