# 效率性分析
## 迭代分析
### 级数估阶分析
针对迭代结构，经常采用的分析方法是级数估阶分析技术。

| 级数                                                                                                    | 阶数  |
| ----------------------------------------------------------------------------------------------------- | --- |
| ***幂次级数***                                                                                            | <   |
| $$\sum k:=1+2+\cdots+n=\Theta(n^2)$$                                                                  |     |
| $$\sum k^d:=1+2+\cdots+n=\Theta(n^{d+1})$$                                                            |     |
| ***对数级数***                                                                                            | <   |
| $$\sum \log k=\log1+\log2+\cdots+\log n=\Theta(n\log n)$$                                             |     |
| ***指数级数***                                                                                            | <   |
| $$\sum a^k:=a^0+a^1+\cdots+a^n=\Theta(a^{n})$$                                                        |     |
| ***分数级数***                                                                                            | <   |
| $$\sum \frac{1}{k^2}:=\frac{1}{1^2}+\frac{1}{2^2}+\cdots+\frac{1}{n^2}=\Theta(1)$$                    |     |
| $$\sum \frac{1}{k(k+1)}:=\frac{1}{1\cdot2}+\frac{1}{2\cdot3}+\cdots+\frac{1}{k \cdot k+1}=\Theta(1)$$ |     |
| $$\sum\frac{1}{k}:=\frac{1}{1}+\frac{1}{2}+\cdots+\frac{1}{n}=\Theta(\log n)$$                        |     |
其中幂级数的阶数可以根据近似积分$\int_0^nk^d\approx\int_0^nx^{d}dx=\Theta(n^{d+1})$来判断，对数级数的阶数可以根据公式来判断。

### 典例
练习一循环结构的时间复杂度是$\Theta(n^2)$，练习二循环结构的时间复杂度仍然是$\Theta(n^2)$，练习三循环结构的时间复杂度仍然是$\Theta(n^2)$.
```cpp
/* Example1 */
for(int i=0; i<n; i++)
for(int j=0; j<n; j++)

/* Example2 */
for(int i=0; i<n; i++)
for(int j=0; j<i; j++)

/* Example3 */
for(int i=0; i<n; i++)
for(int j=0; j<i; j+=2000)
```
练习四和练习五的时间复杂度都是$O(n\log n)$。
```cpp
/* Example4 */
for(int i=0; i<n; i<<=1)
for(int j=0; j<n; j++)

/* Example5 */
for(int i=0; i<n; i++)
for(int j=0; j<n; j*=2)
```
练习六循环结构的时间复杂度是$O(n)$，整个循环仍然可以描述为一个等比级数。这一类结构为外层循环翻倍，内层循环累加：内层运算次数呈现指数增加的趋势，求和级数中最后一项对复杂度的贡献超过前面所有项的和，但是由于只进行了对数次外层循环，最后等价于线性次复杂度。
```cpp
/* Example6 */
for(int i=1; i<n; i<<=1)
for(int j=0; j<i; j++)
```
练习七循环结构的时间复杂度是$O(n\log n)$。这一类结构的特征为外层循环累加，内层循环翻倍：内层是多个对数项求和，最后级数求和得到一个线性x对数级别的复杂度。
```cpp
/* Example7 */
for(int i=0; i<n; i++)
for(int j=1; j<i; j+=j)
```


## 递归分析

### 递归方程分析
另一种分析递归结构复杂度的方法是代数方程分析，既通过引入递归方程来估算算法的复杂度。

通常而言递归方程都是一组差分方程，而差分方程未必通解，但是如果方程的形式足够良好则会存在通解。对于目前最常用的差分方程$T(n)=aT(n/b)+O(f(n))$而言通解是存在的，我们在下面这个定理中予以介绍。

> [!NOTE] Master Theorem
> 对于如下形式的差分方程
> $$
> 	T(n)=aT(n/b)+f(n)
> $$
> （1）如果$f(n)=O(n^{\log_b a-\varepsilon})$，那么$T(n)=\Theta(n^{\log_b a})$
> （2）如果$f(n)=\Theta(n^{\log_b a}\cdot\log^k n)$，那么$T(n)=\Theta(n^{\log_b a}\cdot\log^{k+1}n)$
> （3）如果$f(n)=\Omega(n^{\log_b a+\varepsilon})$，那么$T(n)=\Theta(f(n))$
