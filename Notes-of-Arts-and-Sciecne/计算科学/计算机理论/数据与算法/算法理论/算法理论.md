# 算法概念
算法就是基于特定的计算系统，解决特定问题且具有特定性质的指令序列。一般而言算法所包含的性质包括：输入与输出、确定性、可行性、有穷性、正确性、可读性、效率性等。

| 特性     | 含义                  |
| ------ | ------------------- |
| 输入与输出  |                     |
| 确定性    | 算法可以描述为有限个语义明确的基本指令 |
| 可行性    | 算法的基本指令在对应计算模型中均可实现 |
| 有穷性    | 算法最终会停止             |
| 正确性    | 算法最终会正确             |
| 效率性    | 算法所占用的时空资源较少        |

## 效率性分析
算法效率性的分析主要是分析算法所用的时间资源和空间资源，也称为算法的时间复杂度和空间复杂度。通常时间复杂度衡量指标是进行基本操作的次数，常用的基本操作包括：变量赋值、数字加减乘除、变量大小比较、索引访问。
### 渐进分析
渐进分析强调分析算法复杂度随着数据规模$n$变化的渐进上界$O(n)$、渐进下界$\Omega(n)$、渐进确界$\Theta(n)$性质，通常不考虑计算系统硬件所带来的影响。

> [!NOTE] 算法复杂度
> 对于用一个问题，设算法T和算法S的复杂度分别为$T(n)$和$S(n)$，并且极限存在
> $$
> 	\lim_{n\to\infty}\frac{T(n)}{S(n)} = c
> $$
> 如果$c<\infty$则记为$T(n)=O(S(n))$，如果$0<c<\infty$则记为$T(n)=\Theta(S(n))$，如果$c>0$则记为$T(n)=\Omega(S(n))$.
