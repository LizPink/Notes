# 算法概念
算法就是基于特定的计算系统，解决特定问题且具有特定性质的指令序列。一般而言算法所包含的性质包括：输入与输出、确定性与可行性、有穷性与正确性等，而一个好算法还应当具有稳健性、可读性、效率性。

| 特性     | 含义                  |
| ------ | ------------------- |
| *基本特性* |                     |
| 输入与输出  |                     |
| 确定性    | 算法可以描述为有限个语义明确的基本指令 |
| 可行性    | 算法的基本指令在对应计算模型中均可实现 |
| 有穷性    | 算法最终会停止             |
| 正确性    | 算法最终会正确             |
| *高级特性* |                     |
| 稳健性    | 算法能够处理正确和错误的输入      |
| 可读性    |                     |
| 效率性    | 算法所占用的时空资源尽可能少      |


# 算法分析
这一节我们来介绍如何分析一个算法。所谓算法分析就是对算法各方面的性质进行评价。一个算法适不适合解决某类问题，不仅取决于算法自身的性质，还取决于实现算法的计算模型。而这里的分析是仅仅是关于算法本身的内含性质的评价，因此我们会抽象出不同计算模型的共性，在统一的模型上评价各个算法。
## 理想计算系统
### 图灵机器系统
图灵机系统就是一类抽象的理想计算系统，由于它抽象掉了物理的性质，让我们可以限制在理论上评价不同的算法的好坏。图灵机系统具有如下七个结构：无限纸带（$\rm{\text{Tape}}$）、读写头（$\rm{\text{Read-Wtite Head}}$）、有限控制器（$\rm{\text{Finite Control}}$）、有限状态集合（$Q$）、输入字母表（$\Sigma$）、纸带字母表（$\Gamma$）、状态转移函数（$\Delta$）。
图灵机的运行逻辑分为以下六步：查看当前状态、读取输入符号、查看转移函数、写入纸带符号、移动读写头、更新当前状态。

## 效率性分析
如前所述，算法效率性的分析主要是分析其自身的理论效率，实际算法运行的效率还要考虑其所依赖的物理计算系统。那么在理论分析中主要考虑算法本身所用的时间资源和空间资源，尤其是时间资源也称为算法的时间复杂度和空间复杂度。通常来说一个算法的时间复杂度表现为算法执行所需要执行的指令数目多少，空间复杂度表现为算法执行所需要存储数据的容量大小。
### 规模分析
通常来说一个算法的时间复杂度和空间复杂度取决于任务规模大小，而规模视角正是从任务规模大小的角度出发研究算法的复杂度。规模分析视角经常采用渐进分析法（Asymptotic Analysis），渐进方法是分析学的极限理论在计算机科学中的具体应用。这一节我们介绍在给定的计算系统上介绍这种方法。

通常来说渐进分析发关注随着任务规模变化，算法解决问题所需要的时间和空间复杂度的上下界。如果用$n$来表示问题规模的大小，那么记号$\mathcal{O}(n), \Theta(n),\Omega(n)$分别表示算法复杂度$T(n)$关于问题规模的上界、确界、下界。

从渐进分析法的视角而言，时间复杂度在$O(\ln n)$水平的算法被认为是高效的算法，在$O(n^c)$水平的算法认为是有效的算法、在$O(e^n)$的算法被认为是低效的算法。
