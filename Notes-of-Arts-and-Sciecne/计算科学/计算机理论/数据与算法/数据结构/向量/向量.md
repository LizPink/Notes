向量和列表是两类重要的线性数据结构或者序列（Sequence）结构。
# 抽象数据类型
### 类型接口

| 操作              | 功能                        | 适用对象 |
| --------------- | ------------------------- | ---- |
| ***构造与析构***     | <                         | <    |
|                 |                           |      |
| ***访问***        | <                         | <    |
| `size()`        | 报告向量当前的规模（元素总数）           | 向量   |
| `get(r)`        | 访问秩为`r`的元素                | 向量   |
| `traverse()`    | 遍历向量并统一处理所有元素，处理方法由函数对象指定 | 向量   |
| ***增删改查***      | <                         | <    |
| `put(e, r)`     | 将元素`e`替换秩为`r`的元素          | 向量   |
| `insert(e, r)`  | 将元素`e`插入秩为`r`的位置          | 向量   |
| `remove(r)`     | 删除秩为`r`的元素                | 向量   |
| `deduplicate()` | 剔除重复元素                    | 向量   |
| `uniquify()`    | 剔除重复元素                    | 有序向量 |
| `find(e)`       | 查找目标元素`e`                 | 向量   |
| ***排序***        | <                         | <    |
| `disordered()`  | 判断所有元素是否已按非降序排列           | 向量   |
| `sort()`        | 调整各元素的位置，使之按非降序排列         | 向量   |
