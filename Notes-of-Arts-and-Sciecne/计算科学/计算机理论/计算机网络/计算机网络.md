# 网络传输协议
网络传输协议主要是指外部机器（客户端）与服务器主机之间的通信规则，目前主流的网络传输协议主要是超文本传输协议（Hyper Text Transfer Protocol, HTTP or HTTPS），其中HTTP协议采用明文传输，而HTTPS协议采取加密传输。

## HTTP Protocol
经典的HTTP协议将信息传输过程抽象为请求-响应格式：客户端发起请求、服务器返回响应。一般而言客户端是通过浏览器软件向服务器发起请求，服务器响应请求并且返回HTML\CSS\JS\JSON等格式的数据返回给客户端，最后浏览器再把得到的数据渲染成为网站界面。

## 请求协议
当我们要访问服务器时，客户端会向服务器发送请求动作，其中HTTP协议规定了如下的请求动作：

| HTTP 请求动作 | 说明 |
|---|---|
| GET | 请求服务器指定的资源 |
| POST | 客户端向服务端提交资源（文件或者数据表单） |
| PUT | 客户端向指定的资源位置上传 |
| DELETE | 客户端请求删除服务器指定资源 |
| OPTIONS | 客户端请求服务器对特定资源的 HTTP 请求方法 |
当用户发起请求时，请求会按照一定的格式进行信息编码，其中请求信息一般包含如下的内容：

| 头信息             | 说明           |
| --------------- | ------------ |
| Host            | 服务器域名        |
| User-Agent      | 请求用户信息       |
| Accept          | 请求端接收数据类型    |
| Accept-Encoding | 请求端接收的数据压缩类型 |
| Accept-Language | 请求端接收内容语言选择  |
| Cookie          | Cookie 信息    |
## 相应协议
当用户端发送了请求之后，服务器会根据用户的请求信息决定是否进行响应，不同决定的状态代码如下：

| 状态码 | 说明    | 备注                   |
| --- | ----- | -------------------- |
| 1xx | 请求处理中 | 100                  |
| 2xx | 请求成功  | 200                  |
| 3xx | 重定向   | 301（服务器资源修改，重新请求）    |
| 4xx | 访问错误  | 404（未找到资源）、403（禁止访问） |
| 5xx | 服务器错误 | 503（服务不可用）           |
当服务器决定响应请求时，会返回固定结构的应答信息，应答信息中一般具有如下内容：

| 头信息              | 说明                       | 备注                    |
| ---------------- | ------------------------ | --------------------- |
| Status code      | 状态码                      |                       |
| Content-Type     | 内容数据类型                   | application/json，JSON |
| Content-Length   | 数据长度                     |                       |
| Content-Encoding | 数据压缩格式：gzip ...          |                       |
| Set-cookie       | 设置 Cookie                |                       |
| 应答内容             | HTML、JSON、JS、文件、图片、加密数据等 |                       |
